# 主体框与分割标注

主体标注独立于场景标签、正例和训练划分。坐标为 EXIF 转置后的原图像素，框使用 `[x0,y0,x1,y1]`，右下边界不包含在内；评估裁剪另加 5% 边距。

- `subject_boxes.json`：人工保存的框。`confirmed` 表示人工校验；人工记录覆盖自动建议。
- `subject_box_prelabels.json`：SAM3 自动建议框。取固定提示 `product package` 下最高置信度分割掩码的外接矩形；默认采用与人工确认是不同状态。
- `subject_masks.json`：1,117 张照片的自动二值掩码清单，图片和掩码路径相对项目根目录。掩码由 SAM3 自动生成，没有人工逐像素描边；主体框的人工修正不改变自动掩码。

2026-10-10 已补齐新增 117 张的框建议、分割掩码、矩形裁剪和白底抠图，无检测失败。作者随后确认全部框校验完成、所有框均合理：695 张逐张保存，剩余 422 张按本次作者确认批量记录为 `confirmed`，带 `confirmation_method=creator_bulk_confirmation`。已有人工记录与所有坐标保持不变。备份、作者原话和逐图批量确认清单见 `dataset/review/photos/manual_reviews/full_review_finalization_20261010/summary.json`。

打开 [原始照片待校验框](http://127.0.0.1:8765/?scope=original&filter=boxes_pending)，点击“修改主体框”或“查看当前组的框”。参照 reference 框住目标包装的可见部分，不预留边距。框合适也请点击“确认此框并下一张”记录人工校验；框不合适则先调整。快捷键为 Ctrl/⌘ + Enter，待校验筛选下会自动跳过已确认照片。无法识别目标时选择“无法确认目标”，再保存人工判断，保留照片。
