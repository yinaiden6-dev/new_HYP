【三、全量 Token Correspondence 与 Contribution】

对全部 1117 张，至少分析：
正确候选 vs 图像最强错误候选；
正确候选 vs 融合最强错误候选。
重复候选去重；多个正确候选保留各自结果并说明主对照规则。

逐 Token 保存：
原始索引、类型、位置和区域；
正负候选的最佳匹配索引、坐标与相似度；
次优匹配与 top1-top2 差额；
Delta_i = max_j(q_i·g_positive_j) - max_j(q_i·g_negative_j)。

校验 mean(Delta_i) 等于原始正负评分差额。

保存选定关键配对的完整相似度矩阵及有效索引映射，采用分片和压缩。完整图库保留标量分数，不要求保存所有 1117×5405 配对的 Token 矩阵。

分析：
跨行、跨文字区域和跨包装面的对应；
几何残差；
多对一聚集；
目标覆盖率；
近似并列匹配；
关键区域和非关键区域的正负贡献。

用成功对照及候选 Token 数控制判断异常，不能仅凭跨行或匹配集中就判定机制成立。

将贡献分解到：
关键数字/规格；
差异布局；
公共文字；
图案/颜色；
主体其他部分；
背景；
模板 Token。

每个区域计算 C_R = sum(Delta_i in R)/N，并报告正贡献、负贡献、净贡献、集中程度与 Token 数。
用于守恒的区域必须互斥或采用归一化软分配；语义重叠标签另存。
视觉 Token 不等于单词，跨多行或多区域时保留不确定性。

明确区分：
关键区域没有形成正确优势；
关键区域有正确优势，但被其他区域抵消；
多个区域共同支持错误候选。

为每张图提供可查看的匹配关系和贡献解释，不只输出热力图。

【七、编码审计与受控干预】

定位新旧编码差异：
图像字节、解码像素、EXIF、resize/crop、处理器张量、模板；
模型 checkpoint/revision、eval 状态；
精度、attention、投影、归一化；
软件环境与设备。

有条件时比较视觉骨干、投影前后和最终 Token，确定差异首次出现的位置。不要只重复最终编码，也不要未经验证就归因于 GPU 型号或 CPU 卸载。

记录同运行时重复性、新旧特征误差、Token 余弦、正负差额与排序。
旧缓存无法复现时继续全部冻结分析，新运行时独立标记，并重新编码干预所涉及的 Query 和对照候选。
新旧混合图库的条件排名不能当成新运行时完整图库准确率。

图像编辑明确使用 Pillow/OpenCV 等确定性像素操作，不使用生成式重绘：
布局实验只移动已有字形或改变可控换行；
其他关键细节实验在可核验素材上做局部遮挡或替换；
配套原图、sham、等面积非关键区域编辑等对照。

布局实验保持文字内容、颜色、容量和其他非目标因素一致，验证像素变化范围、字形守恒与编辑痕迹。
事先定义编辑后的预期匹配关系，不能无条件沿用原身份标签计算准确率。

覆盖多个独立身份、主要错误类型和成功对照。
布局分别测试更符合 Query 与更不符合 Query 的方向性响应。
不能根据编辑后是否改善来筛选案例。

计算：
edit-minus-sham；
正负差额；
逐 Token 特征变化；
匹配对象是否切换；
切换与未切换 Token 的贡献；
关键区域与其他区域是否抵消；
适用情况下单因素与组合干预的交互作用。

冻结 Token 删除、图像遮挡后重编码、改变匹配规则是不同操作，不能混称因果归因。
MaxSim 优于固定对角匹配受到 max 运算的结构约束，不能只凭这种比较证明身份布局机制。
