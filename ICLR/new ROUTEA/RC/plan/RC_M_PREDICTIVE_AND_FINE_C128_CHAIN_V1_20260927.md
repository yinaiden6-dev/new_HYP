# 下一轮：前瞻响应预测与细性质的完整C128纠错核算

用户授权：进行下一轮，并补齐细性质对原有收益的核算；持续监督至本轮完成，新旧程序、结果与说明归档GitHub。本方案不覆盖或改写旧实验。

## 两条链及范围

1. POST响应预测：复用H593前128中target-present120张、45组的原折冻结模型与内容缓存。局部探针用于预先生成预测；全局封存预测及SHA后，才计算新M端点。已打开query上的新干预预测，与未观察query/跨数据集确认分开。复用历史M多项式读出认识，不重复声称首次预测M到内容变化。
2. 细性质归因：复用11张完整自然C128的相位/幅度输出，补相同面板的13个配准世界。沿原NATIVE7、M_FREE、POST传播并重算全部128候选，核算原纠错保留/消失/恢复、新增误伤及第三候选胜出。8张与结果无关的选择面板、3张指定纠错案例分开报告。相位/幅度与配准均以各自数值后端的原生端点为锚，漂移单列。

仅有固定target/wrong的实验不能替代完整候选核算。11张现有完整细性质缓存也不能冒充全部128或593的收益归因。本轮能闭合该面板内各项预定干预对完整候选决策的作用；扩全128仍缺其他query的完整J/P缓存，未在本链暗中启动新的GPU采集。

## 提交与继续运行

全部CPU执行，线程4、内存32GB，每次10分钟。预测probe8片 → seal → endpoint8片 → join → independent check。

旧phase11片（8片直接复用、3片补CPU读出）→ phase join。

配准首候选完整13臂pilot → 50片逐arm可恢复采集 → context join → 11片冻结下游传播 → fine join。

两链独立验收后总验收。时限前主动保存，以75返回或外层timeout124触发同Job ID续跑，最多32次；其他错误终止并检查，不用续提掩盖失败。普通CPU排队，最多4个本链就绪任务加入dev CPU共同排队；依赖未满足任务不占dev通道。未修改其他实验任务。

首候选是正式计算的一部分，后续跳过已经验证的输出。它核验完整路径、断点及运行时间，不按科学结果决定是否继续某个干预。

## 可验收内容

- 冻结输入、原折模型、程序和候选身份轴；保存逐patch分数、argmax及必要的预测/干预中间量。
- 预测SHA先于端点；真值标签只参与末端评价，不能用于预测器规则选择。
- 完整C128动作以原0阈值HOLD/SWITCH核算；每条分差记录明确其候选范围。
- 贡献集合允许重叠，不承诺唯一因果或把交互硬分成三个独立百分比。
- 同时归档正向、零、反向和数值域边界；工程PASS与科学命题支持分开。
