## 4. Exact NATIVE7 head definition

This stage trains only the selected native family. COMMON3 is not retrained or
reported as a competing model.

For each arm `a` independently:

`z_a(c;q) = b_a + w_a^T f_a(c;q)`,

where `w_a` has six float64 scalars, `b_a` has one float64 scalar and the head
has exactly seven trainable parameters. A/B/C therefore have 21 scalars in
total, but each matched arm has nominal capacity seven.

The feature order is immutable:

1. fresh-D1 challenger-minus-winner base gap divided by the query's C128 score
   standard deviation;
2. symmetric challenger-versus-winner REAL local score;
3. symmetric effective visibility mass;
4. symmetric REAL score divided by effective mass;
5. symmetric REAL-minus-query-roll response;
6. symmetric REAL-minus-reference-roll response.

Arm masks remain:

- A ALL: query ones, reference ones;
- B QUERY: candidate query map, reference ones;
- C PAIRED: candidate query map, candidate reference map.

Pair64 BALANCED32_V1 uses roll-by-one; BALANCED32_V2 uses half-map rolls.
current64 uses half-map rolls. Exact-zero and duplicate feature columns and
matrix rank are diagnostics; no column may be removed or reparameterized.
A/B/C have equal nominal capacity but cannot be described as equal effective
capacity when degeneracies differ.

## 5. Frozen training population and order

- Pair64: 64 rows of shape `[1,6]` with their sealed switch labels;
- current TRAIN32: 32 query matrices of shape `[127,6]`, one row for every

The diagnostic design matrix is `64 + 32*127 = 4,128` rows per arm. Pair64
order is its sealed ordinal order. TRAIN32 is sorted by frozen execution

The term cross-fit is limited here:

- all fresh-D1 base/features are OOF with respect to their canonical D1

- the action head is trained once on fixed Pair64+TRAIN32 and evaluated once

EVAL32 cannot enter initialization, loss, standardization, early stopping,
threshold choice, arm choice or optimizer control flow.

## 6. Exact loss and optimizer

For Pair64 row `i`, with switch label `y_i` and logit `z_i`:

`L_pair = mean_i alpha_i * BCEWithLogits(z_i, y_i)`,

where `alpha_i=4` for HOLD (`y_i=0`) and `alpha_i=1` for SWITCH (`y_i=1`).

For each current TRAIN32 query, let `z_j` be logits for all 127 non-winner
candidates:

- target is the base winner:
  `L_q = 4 * softplus(max_j z_j)`;
- target is a non-winner at challenger index `t`:
  `L_q = softplus(-z_t) + 4 * softplus(max_{j != t} z_j)`.

J1 must have target-absent count zero. If not, training stops before optimizer
construction; this contract does not invent an absent-target loss or insert a
target.

`L_full = mean_q L_q` over exactly 32 TRAIN queries and
`L_total = L_pair + L_full`. No extra coefficient, minibatch rebalance,
clipping, auxiliary loss or C_BIND loss is permitted.

For A, B and C independently, preserve:

- seed `17`;
- one float64 linear head;
- all-zero weight and bias initialization;
- AdamW, learning rate `0.03`, weight decay `1e-3`;
- exactly 2,000 full-batch updates;
- no early stopping or checkpoint selection;
- finite loss, gradient and parameter checks at every update.

Producer model-update count is exactly `3*2000=6000`.

## 8. A0 target-free action seal

Only after T0 validation may A0 load the three frozen heads and the sealed
current64 EVAL feature payloads. A0 may read result-blind EVAL membership, but
must not open J1 target fields or any outcome artifact.

For every query, arm and REAL/C_BIND path:

1. score all 127 non-winner candidates;
2. choose the arm's own strongest challenger by logit descending, then lower
   representative physical row;
3. if the strongest logit is strictly greater than zero, perform one SWITCH;
4. otherwise HOLD.

HOLD preserves the complete fresh-D1 base ranking. SWITCH moves only the
selected challenger to rank one and shifts candidates that previously preceded
it down by one. No second action is allowed.

Candidate reorder jointly permutes candidate keys/base/local bundles and must
replay after restoration. C_BIND preserves query, destination candidate axis,
base scores/gaps and winner, while moving the complete local bundle by the
sealed fixed shift of 64. It is inference-only and never enters training.

A0 seals all logits, proposed challengers, HOLD/SWITCH decisions and final
rankings before target join. Successful statuses are:

- `ROUTEA_N2_FRESH_D1_MATCHED_THREE_ARM_TARGET_FREE_ACTIONS_READY`;
- `ROUTEA_N2_FRESH_D1_MATCHED_THREE_ARM_TARGET_FREE_ACTIONS_VALIDATED`.

EVAL outcomes.

## 10. Fixed conditional decision gate

No threshold is changed. C is conditionally actionable only if all conditions
hold on EVAL32:

1. D1+C REAL final top-1 is strictly greater than frozen RAW+C `28/32`;
2. D1+C REAL MRR is at least `0.9014136904761905` and is not below D1 alone;
3. REAL rescues exceed breaks and breaks are at most one;
4. for every canonical D1 fold, the mechanically computed value
   `sum_q(1[D1+C final correct] - 1[RAW+C final correct])` is non-negative;
   the subset whose action strings differ is reported only as a diagnostic and
   cannot change this gate;
5. fresh-D1 C128 target recall is not below RAW C128 target recall;
6. D1+C REAL top-1 strictly exceeds both D1 alone and D1+C C_BIND;
7. at least one REAL rescue occurs and C_BIND retains fewer than all REAL
   rescues;
8. all input, independent-training, action, reorder and binding checks pass.

REAL correctness increment must strictly exceed C_BIND increment. A tie with
RAW+C, D1 alone or C_BIND is not promotion.

The reducer must publish all individual actions before the status, so every
gate is independently replayable.

## 13. Failure taxonomy and stop conditions

Failures must be classified, not collapsed into ownership failure:

- J1 authority, label-consensus, corrected-axis, population or disjointness
  failure:
  `N2_NATIVE7_J1_POSTSEAL_JOIN_ABORT`, zero updates, next stage null;
- input hash/schema/shape/finiteness or fallback binding failure before T0:
  `N2_NATIVE7_PREOPTIMIZER_INPUT_ABORT`, zero updates;
- non-finite loss, gradient or parameter, wrong update count, or unequal arm
  recipe:
  `N2_NATIVE7_TRAINING_ABORT`;
- training replay mismatch:
  `N2_NATIVE7_INDEPENDENT_TRAINING_REPLAY_ABORT`;
- target-free action seal/reorder/C_BIND reconstruction failure:
  `N2_NATIVE7_TARGET_FREE_ACTION_SEAL_ABORT`;
- finite validated training but C fails retrieval/no-regret gates:
  `N2_FRESH_D1_ACTION_CONDITIONAL_NO_GO`;
- REAL retrieval improves but does not strictly beat C_BIND:
  `N2_FRESH_D1_RETRIEVAL_ONLY_NO_CANDIDATE_BINDING`;
- all Section 10 gates pass:
  `N2_FRESH_D1_CANDIDATE_BOUND_ACTION_CONDITIONAL_GO`.

Engineering aborts have `scientific_GO_or_NO_GO=null`. Conditional GO/NO-GO
is internal opened evidence and never overwrites the candidate-recall NO-GO.
