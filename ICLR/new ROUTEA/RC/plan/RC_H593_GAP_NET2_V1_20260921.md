## 2. 冻结动作

原127个challenger logits中第一个最大值为m，次大值为z2，`d=m-z2`，beta>=0。

原m>0：整条127分数逐位保持。原m<=0：计算`g=((m+0.0)+beta*d)+bias`；只有g>0才把原最高challenger的分数替换成g并SWITCH，其余分数不变；否则保留原分数。HOLD输出RAW答案，不是未知类拒答。

新门仍可能误伤原正确HOLD。保留旧正SWITCH不等于零损失。全程FP64，固定运算顺序，不重排候选。

## 4. 直接净增的有限搜索

对于每条训练HOLD，offset为`u_i(beta)=m_i+beta*d_i`。固定beta时，对所有binary64 bias决策区间做精确净增优化。

beta候选集合由训练数据决定，不使用外层结果指定角度或截断范围：

1. 包含0和上轮本折GAP_BIAS2的beta。
2. 对所有训练HOLD对i<j，计算正、有限交点`(m_j-m_i)/(d_i-d_j)`，不同d才有交点。
3. 包含交点FP64值、紧邻前驱/后继，以及排序后相邻交点之间的中点（也包含0到首交点的中点）。
4. 包含最后交点之后`last+max(1,abs(last))`的有限代表；没有正交点时包含1。
5. 去重排序。只声称在这个确定有限集合上找到最优，不声称遍历全部连续二维空间或整个FP64平面的全局最优。FP64舍入可在数学交点附近产生更细的模式，本协议不隐瞒这个边界。

固定beta，按offset降序或按实际bias转折点升序，按相同转折点分组计算前缀delta总和。所有候选bias模式中选最大净增；并列选改动更少的HOLD，再取对应区间内最接近0的bias。显式保留disabled无改动选项。

全局先要求净增**严格高于上轮本折GAP_BIAS2**。无严格提高时，直接保留旧beta/bias/disabled，不因并列再改变行为。有严格提高时按以下顺序选：

1. 净增最大；
2. 改动的HOLD最少；
3. `abs(log1p(beta)-log1p(beta_old))`最小；
4. |bias|最小，再较小beta，再较小bias。

旧beta始终在集合里，旧bias本身保留作对照；因此内层净增不能比旧模型低。这个工程保证只针对训练校准记录，**不保证外层仍有492、更不保证超过492**。不给外层5张误伤或30张可救机会添加特例。
