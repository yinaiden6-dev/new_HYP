# A/J/P 配准对照：冻结的新分支

目的：区分 P 张量自身的内部结构与 P 在 A/J 内容背景中的配准作用，并在同一组固定模型上追踪其对外部校准及 POST 表示的传播。此分支不优化准确率、不新增模型、不调参数。

## 数据与费用

只用已完整采集的 phase9 面板：索引 78、82、93、96、100、101、104、108、118；九个身份组，每组原先锁定的 target 与最强自由内容 wrong，共18对 query/reference。原先按组取样的规则和候选位置不变。该面板的相位实验结果已经读过，因此它现在是已打开的机制开发面板，不能再次称为未触碰复验。

前128张的通常输出缓存不能逆推出未保存的 J/P 张量；本次不会以全128为名报告九组结果。phase9 的两层 A、J、P、原 DPT 置信度及几何都已在 CPU 缓存，全部可复用，不需要新图像编码、匹配器或 GPU 前向。

原缓存每次双向 DPT 约15秒，当前首对 CPU native 重播实测10.33秒且 confidence 逐元素相同，见新结果根的 `native_timing.json`。本轮522次双向 DPT，预计90–135个4-CPU节点分钟，加不变量和 I/O；18个独立 pair 分片，每片10分钟，预算430秒时保存当前臂并以75返回供同 Job 续跑。总墙钟由并行与排队决定。

## 固定的有限实验

RoMa 的实际接口是两层 appearance 特征 A0/A1，以及仅在末层相加的 `A1+J+P`。DPT 接着执行逐patch LayerNorm、投影、空间卷积／缩放／融合。`pos_embed=False` 不意味着 DPT 对任意平移等变。

在50×50粗网格固定使用四个循环平移：X±4格、Y±4格。4为预先指定的偶数，兼容 DPT 的 stride2；不根据结果选择幅度或方向。A/J/P各一个移动开关，形成完整2³立方体；A开关同时移动 A0 和 A1。000共用原生输入，合计29个独特臂。两图对应的输入侧使用同一方向。四方向是同一组的重复，不增加样本组数。

循环平移保留每个张量的向量多重集、全 channel Gram、空间 Fourier 幅度及环绕局部结构。它改变分量间的配准，也改变张量相对有限解码网格的摆放。P开关为0的分支，P完整张量及其空间排列逐元素不动。

本轮 NATIVE 指 COARSE DPT 的原输入在 CPU 上重放，不是原系统最后 HR1 的 M。绑定效应只在同一粗阶段端点的干预之间比较。

以下不变量必须通过：

1. 每个 A0/A1/J/P 的逆平移恢复完整张量，逐元素精确。
2. 全 channel Gram 的不变性来自同一行置换的代数恒等式；另对预先固定的32个均匀通道数值验证 Gram。P全通道二维 Fourier 幅度用 FP64 数值验证，相对误差门 `1e-12`。
3. 111 的实际 FP32 `A1+J+P` 必须等于000求和后同移；DPT真实 norm hook 的输出也必须等于原 LayerNorm 后同移。完整 DPT 不设等变性假设。
4. NATIVE 双向 DPT confidence 必须与同 CPU 原 capture 逐元素相同。每臂 sigmoid 后的整数矩形池化用独立 NumPy 算法核对，绝对误差门 `2e-12`。

## 预先指定的比较

记每个方向的候选相对端点为 `g_abc`，a/b/c分别是 A/J/P 开关。

主对比是四方向内平均的：

`[g000 + g111 − g001 − g110] / 2`。

它比较两种绝对摆放下的对齐与错位；纯加性的 `f(A,J)+h(P)` 响应会抵消。并行保留：

- `110−000`：P完整不变，仅 A/J共同移动。
- `111−000`：所有输入共同移动，量化解码网格／边界／池化敏感性，不能预设为零。
- `001−000`：只移动 P。
- 固定 A 时的 J×P 交互：`011−010−001+000`。
- A移动时的 J×P 交互：`111−110−101+100`。
- 两个条件交互之差，即三阶交互。

上游主端点为同组 target−固定 wrong 的 logM 差，同时保留两者分别变化以及 dense confidence 平均值构成的对照。九组等权，四方向先在组内平均；bootstrap仅为固定种子20260927的探索性九组重采样，10000次。

## 不是只看 M：保留相加／归一化后的具体变化

每臂两侧保存完整 DPT confidence、FP64 token weights、M，并保存逐patch的：

- Var(A1)、Var(J)、Var(P)、Cov(A1,J)、Cov(A1,P)、Cov(J,P)。
- 总和的方差、FP64方差恒等式残差，以及实际 FP32 加法带来的舍入残差。
- A1+J 与 P 的模长和夹角，SUM模长。
- DPT实际 LayerNorm 后的完整 FP32 SUM张量，以及相对原 LN 方向的 cosine。
- 111 confidence 按名义尺度逆平移后与原图的差；dense sigmoid 均值与 exact token-pool 均值。

A/J/P大张量不重复保存29份；保留完整源文件 SHA 与确定性的网格索引配方，能够无损恢复所有变换输入。新 LN张量预计约11GB，不能只保留检索统计或删掉中间量。

交叉项可说明绑定改变相加向量和归一化方向的哪一部分，但相关性不是完整中介因果。接口只读取 A0 与 `A1+J+P`；保持总和不变的 J/P补偿改变在此接口不可区分。这是唯一分解的结构限制。

## 同组冻结传播链

上游29臂完成并验证后，直接运行缓存上的原折 NATIVE7、M_FREE 和 POST_REAL。复用已封存的原折适配器、投影层、head和query hidden，不重新训练。按原标准一致更新 M及其派生量，POST直接接收每个候选的真实 M。

这是 M-only 的条件传播：外部原局部权重形状、内容以及其它原量保持固定，只更新 M及代数派生量。干预后的完整置信度场也会保存，但这里不会把它所有变化都灌入外部评分。因此它检验 M 通路的传播，不是所有上游路径的总效应。

只改变锁定的 target/wrong 两个候选。如果 RAW赢家是第三候选，则其原 M/L 保持固定；如果属于该配对，则使用自身干预值，HOLD为0。保存每臂 patch MaxSim、argmax、L、分开端点与 action gap。这里不重新排名完整128候选、不报告全C128准确率。

完整顺序为 `prepare → 18×worker → join → 9×bridge-worker → bridge-join`。各阶段都有独立 validation，缺依赖返回75，算术或来源错误返回失败。最终同时报告上游、逐patch相加／LN变化、固定外部／内部传播，不止报告 M。

## 能回答与不能回答

若保持 P自身结构的错位干预破坏候选区分、对齐恢复在共同位置控制后仍有作用，这支持**冻结解码接口中的跨分量配准**参与判别，不能把结果解释为P自身分布结构完全足够。若效应不稳定，则需要承认这一配准解释未在本面板成立。

这不是把照片真实移动后重新编码。卷积、padding、resize、LayerNorm方向与token池化均可能参与；111对照量化这些路径而不能完全消除。该有限实验不证明唯一语义绑定、空间真值、普遍必要性或身份充分性，也不以未显著推出等价。
