## 可训练融合适配器的边界

现有 200 配置包含一个 4096 参数适配器，其输入特征已经缓存，但它每次更新会改变 token、匹配分数和梯度。这些动态输出不能靠一次冻结 RoMa 前向永久预计算。CPU 在数学上可以执行这段训练，但当前 GPU 训练路径不能未经时间与数值验证就声称迁往 CPU 会更快或逐位相同。已经恢复的融合训练仍沿用原 GPU 检查点续跑；它不重复提取 RoMa 特征。

因此，固定 RoMa 的分析实验可以实现“GPU 数据采齐，CPU 完成下游”；不能把适配器尚未训练完计为原始数据缓存缺失，也不能把全部 GPU 任务完成时间归因于 RoMa 重算。
