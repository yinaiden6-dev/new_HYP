# processed128 冻结模型回归检验

用户授权：从 `1/processed` 取一部分图，检验原本较强的 ColNomic 检索是否会被当前模型改坏。

这是已知药盒图库的合成处理图片回归测试，不是新的外部确认，不训练、不调参，也不修改既有头或历史结果。

## 抽样与标签

- 先冻结清单，再计算任何本轮检索结果。种子字符串 `processed128-regression-20260916-v1`。
- 使用目录自带 `origin name/processed_origin_name.csv`，核对全部 2000 张处理图。
- CSV 的显示名称会去掉原文件名尾部空格或下划线；对应 reference 时使用处理文件名 `__` 之前的完整原始 stem，防止把正常文件误判为缺失。
- 原图名称必须在原有完整 gallery 中精确且唯一对应一个物理 reference。重名或没有对应 reference 的项进入排除表；不按检索成绩筛选。
- 对合格的不同原图名称按种子加名称的 SHA256 排序，取前 128 个；每个来源按种子加文件名的 SHA256 排序，取一张处理图。不专门选 RAW 正确项。
- worker 使用不带身份的图片别名，标签由 curator 单独保存；所有预测密封后才合并标签。
- 记录与 H593 训练身份及图片 SHA 的重叠，分别报告。CSV 中共享 XML 的来源按连通分量一起 bootstrap，避免把关联来源当独立样本。
- 查询使用 EXIF 校正后图像；参考与原模型一致。图像 SHA、模型、处理器、gallery、数值循环、头、程序及启动器均固定。

## 固定比较

使用原完整 5413 物理 reference／5412 修正身份库，RAW 自然 C128，不插入 target。复用原 ColNomic 编码/MaxSim、RoMa soft visibility、FP64 C4 和 127 challenger HOLD/SWITCH 推理。

主头 COST1、次头 CE，均为 20260913 冻结的 full-H593 头；额外记录同 bundle 的 COST4、GROUP_COST4、RAW2_CE 及候选绑定打乱对照。不使用 OOF 折头或旧 ORIGINAL7 代替。全部阈值不变，最大 logit > 0 才 SWITCH。

主要报告 RAW 与各头的正确数、相对 RAW 救回/损失/净增、RAW 正确样本中的损失率、C128 遗漏、每张发生改变的图片。按处理类型和训练身份重叠分层为描述性结果。

以来源 XML 连通分量重采样 100000 次，种子 20260916，报告 query 加权净增的 95% 区间。样本没有观察到损失也不等于总体无损保证；本轮不另设或调整科学 GO 门，不因成绩换头或追加有利样本。

## 执行

16 个分片，每片 8 张。RAW 每片 10 分钟，RoMa 每片 15 分钟，GPU 1、CPU 8、内存 96G；先跑一个工程分片，余下分片依赖它成功。CPU 核算自动在所有预测完成后执行。

独立检查包含：原数值循环和 head/action AST 一致、RAW 独立排序、逐候选 FP64 C4 重放、NumPy logit/action 重算、预测与标签一一对应、救回减损失恒等于准确数变化。
