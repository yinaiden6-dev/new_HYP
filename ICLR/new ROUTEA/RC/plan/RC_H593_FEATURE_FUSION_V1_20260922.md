# H593 粗细特征融合：首轮实施与试运行

用户已授权开始。目标为 ColNomic 输出端的单图特征融合，四来源 COL_ONLY/COARSE/FINE/COARSE_FINE 与两种评分 FREE/ROMA_WEIGHTED，共八臂。独立于正在运行的坐标精度及质量算子实验，不修改它们的冻结代码。

## 第一阶段：实际执行的资格试运行

使用原 H593 execution ordinal 0 的 query 和其全部自然 C128 reference，不按正确/错误、身份、分数选择图片。当前 GPU 任务仅建立特征提取、完整 128 候选零适配重放和反向传播接口资格；不读取身份标签、不训练自然数据、不评准确率。不能将其标记为八臂训练完成。

固定 RoMaV2 封存 checkpoint、precise 输入预处理和 ColNomic tokens。粗特征：DINOv3 层 11/17 各 1024 维；细特征：VGG LR800 与 HR1280 两阶段各 scale1/2/4（64/128/256 维）。逐图编码，EXIF/canonical cell 坐标上以 floor/ceil 矩形 FP64 均值对齐，保存 FP32 池化值、直接 CPU 均值检查及几何绑定。完整高分辨率激活不落盘；不声称池化文件支持完整激活重放。

对首个候选（自然轴 index0，不用 target）额外执行一次完整 RoMa，并用 hooks 核对独立抽取与原前向中的所有八个对齐特征块逐位一致；同时要求该对原生可见性与封存缓存逐位一致。其余图片只运行单图 descriptor/fine feature encoder，禁止意外调用 matcher/refiners。按图片SHA+frame+grid+原token SHA建缓存键，每项可恢复。

容量控制：各来源每个块先 LayerNorm，拼接后用固定 seed20260922 的随机符号投影到128维、再 LayerNorm；不使用标签或拟合投影。所有来源使用同一形式128→16→128无偏置门控，共4096可训练参数。down seed17随机初始化，up零初始化，门幅0.1：`z * (1 + 0.1*tanh(up(down(f))))`。只在MaxSim评分中归一化一次，零初始化逐位重放旧评分。该投影是首轮容量受控实现；无增益不能外推为所有粗细特征融合均无效。

复用原 u/v，FREE 改为全1权重，分别保存完整128候选四统计、全部127×6决策输入、free/weighted命中和逐token贡献。首轮不把训练好的旧头参数移植为“无训练新模型”。合成测试验证零初始化、上下层有效梯度、可微六特征与旧字面公式一致、候选重排等变性，以及直接CPU池化核验。

## 后续训练协议及执行边界

资格通过后扩展为原 H593 全部图与自然 C128 联集，按唯一图片与几何去重提取。原五折按身份/来源隔离；基础编码器冻结，适配器和相同形式七参数头仅用该折TRAIN检索标签学习。八臂使用相同来源划分、成本/CE定义、预算、种子集合和保持/竞争规则；容量不同项需单列。当前文件固定来源、融合算子和缓存协议；全量训练步数/批量及作业必须在资格计时后另行冻结，不能基于held标签选择。

现有 RAW、COST1、CE 及 learned ColNomic-only 统计头原结果保留，另设无适配器的同协议训练对照，以分离优化器/预算变化。当前593是已开发分组OOF，不宣称新外部确认。593分母保留23例自然C128目标缺失，候选召回未改善；若后续更换全库编码另开评价。采用前做processed128回归，GroZi/ISIC作为已打开的迁移复核，RPC仍为诊断。

冻结训练前须明确有/无匹配权重的比较包含整体质量、两侧权重及其控制列共同变化，是整个匹配证据包的附加价值，不将差异单独归因于坐标或某个层。模型使用RoMa训练过的VGG参数时称“无RoMa匹配器”，不能称完全不依赖RoMa预训练。
