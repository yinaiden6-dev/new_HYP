# 将 M 上游通路干预接回检索决策

用户要求继续补齐“有用信息是否在 query/reference 交互中形成”的实验。现有 M 内部通路保存了每个候选的 12 个分支、粗与细化阶段输出，但最终仅按 M 的候选排序/相对差值诊断。本实验补齐实际检索决策读出，不重复 RoMa 推理，不改现有在运行程序。

## 输入与统一读出

原 H593 分组五折、自然 RAW C128、593 分母（含 23 个目标不在候选内的 query），沿用原训练顺序与检索标签。读取现有 inside 的每候选二进制中间量及独立验证清单；读取评分算子实验已保存的 free_maxsim 向量、RAW 标准化分差和原始排序。

12 分支分别取 COARSE、HR1 两个端点，共 24 臂，另加 FREE（M=1）对照。为保持原浮点运算，按保存的两侧均值用 torch FP64 sqrt 计算 M；S 使用 `M * sum(free_maxsim) / token_count`，不改成 `M * 已求均值的分数`。两侧局部加权关闭，空间滚动控制列为零，L=S/max(M,1e-12)。原生 A1J1P1_HR1 的全部四统计和六输入必须逐位复现原 M1Q0R0；FREE 必须逐位复现 M0Q0R0。

每臂报告固定小头与同协议重训两种结果，COST1 主、CE 辅。固定头使用已封存的原生 M×自由内容重训头；重训使用原 2000 步 AdamW、lr=.03、weight_decay=.001、FP64 和原自然训练顺序。原生简化头、FREE 头直接复用已封存参数和完整 logits，并逐位核对，不重复训练旧基线。相同训练输入、目标、算法的重复臂可复用本折已训练参数，须保存输入 SHA 和复用来源。原完整 COST1/CE 决策另外保留为基线。

## 预先指定的主要比较

1. COST1 重训：A1J1P1_COARSE 对 A1J0P0_COARSE。比较粗预测头中的跨图上下文＋软对应输入包，条件是原始外观路径固定。
2. COST1 重训：A1J1P1_HR1 对 NO_REFINER_DELTA_HR1。比较原几何/采样不变时，细化 confidence 增量对实际检索的作用。

两项均报告 paired 救回/损失、准确率、MRR，以及 64 个组件的配对 bootstrap 区间。两项主要比较各给 97.5% 区间（Bonferroni 家族控制）；其他比较为探索性 95% 区间。固定头下降若可被重训恢复，需与分布/校准变化区分。所有臂全部报告，不按留出结果挑选模型或种子。

A1J0P0 的粗端点仅保留预测头的单图外观输入；其 HR1 仍包含原生配对细化增量，不能称为“无跨图信息”。J/P 来自依赖链；零干预改变输入分布。本实验回答条件通路与固定读出训练配方下的效果，不能证明跨图交互在所有模型里不可替代。直接粗细特征融合的原实验继续独立执行。

## 执行与数据留存

纯 CPU。先以自然 query000 的完整 C128 验证桥接公式、原生/自由基线逐位一致及独立 NumPy 特征回放，不读该 query 身份、不训练。全部 593 个 inside 输出完整后，按 query 保存来源、两侧均值、M、S、L、全部127×6输入与 free_maxsim 原文件引用。每次 CPU 建表片至多约 240 秒，可从已验证 query 续跑；不重新提取图像/特征。

全量输入封存后提交原五折训练，全部预测封存后才读取留出身份做汇总。保留每臂参数、全部127 logits、HOLD=0、最终选择、训练时间、原文件 SHA、逐query救回/损失。原生简化头与原完整头的已有结果须完全复现。每折独立进程重训复核新臂，并用 NumPy 核对 logits/动作。

新执行器以依赖回调跟随现有 inside 续提链；等待期间不占计算节点轮询，不更改原 GPU 作业。输出目录 `results/rc_h593_m_path_readout_v1/`。当前为已打开的 H593 开发证据，不新增外部确认或 ownership 主张。
