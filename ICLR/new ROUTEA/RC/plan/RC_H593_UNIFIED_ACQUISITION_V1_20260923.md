# 同一图片对统一采集，三个 CPU 消费者

用户同意将各实验在同一次前向可得的必要字段一起保存，避免数百/上千任务分别重复采集。本版本保持原内部通路、视觉干预、坐标干预定义、C128、FP64 统计、原验证器与全部593查询。

## 数据生产

每个 query/reference 对最多执行一次原图完整前向，同时获取：七阶段双方向 token 权重及16网格诊断、内部12条置信度路径的原注册字段、完整 coarse matcher warp/confidence、原图坐标矩和内容贡献。六个视觉变换与三个坐标精度变换分别计算其必要的新输出。

原图前向、坐标三臂共享未变的 query/reference 单图描述子和粗 matcher 输出；视觉六臂共享未变侧描述子。缓存键绑定实际输入，并逐位检查命中输入。原始科学模块不修改。已有三组 part/query 直接复用，只有缺项进入生产；完整融合特征银行不重新提取。

每个 pair 原子写入一个公共 capsule，包含三组需要的新字段、来源、执行 authority 和真实前向次数。完成任一 pair 后中断不需重算该 pair。15分钟GPU短任务在约640秒停止领新 pair，保留落盘时间。中间数据按已注册消费者需求保存，不无差别保存TB级全分辨率激活，不声称支持任意未来新干预。

## CPU 消费与资格

CPU 导出器将公共 capsule 写入原三组科学格式，已有 part/payload 不覆盖，新增数据记录统一执行来源；每组调用原独立验证器。全部数据齐全后原 M 读出、坐标五折与诊断、汇总均在 CPU 进行。

先用自然 query000 前8个候选，逐位比较统一采集输出与三组独立封存结果：全部阶段字段、全部内部路径、全部坐标干预/C4/MaxSim中间量。必须确认8次原图前向同时供三组使用，而非原来的24次。通过后第一个新完整query须通过原CPU验证器，才扩展其余。资格失败不更换科学门或容差。

原待运行重复采集已 held，原运行任务允许收尾；统一生产通过后再取消被替代的 held 任务并启动后续生产。融合训练独立继续，其动态参数输出不能一次预计算。
