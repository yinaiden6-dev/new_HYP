# Route A RC — CW0 Connected-Window Proposal-Recall Contract V1

Date: 2026-08-09  
Status: **FROZEN BEFORE CW0 TARGET-JOIN TRAINING**  
Seed: `17`  
Claim level: engineering and inner-OOF proposal-recall qualification only

## 1. Why the execution order must change

The V2 raw connected-prejoin runtime gate passed, but it did not test whether
the correct reference proposed the connected region:

- 32/32 queries had at least one connected H1 from some C128 candidate;
- all 273 active H1 masks were dense single 4-neighbour components on both
  query and reference endpoints;
- after the frozen target join, the true reference had any H1 on only 7/32
  queries and had both directional H1 on only 3/32;
- A-to-B and B-to-A did not produce a common target region at the frozen
  two-endpoint IoU 0.5 gate on any of the 32 queries.

Therefore the prior order

```text
raw hard proposal -> only legal slots receive representation gradient
```

is circular. A positive whose raw target slot is H0 cannot learn the
correspondence needed to create that slot. The passed raw prejoin is preserved
byte-for-byte as a negative baseline; it does not authorize formal R0 training.

CW0 reverses the order:

```text
soft connected-window representation warm-start
-> freeze the shared adapter
-> regenerate hard target-free connected proposals
-> qualify target proposal recall
-> only then build the connected cross-fit verifier
```

## 2. Non-negotiable target object

For every query/candidate/hypothesis, the target latent object is a pair of
complete masks `(W_q, W_r)`.

1. `W_q` and `W_r` must each be one dense 4-neighbour-connected component.
2. A seed patch only initializes a window. It is never target evidence.
3. Sparse correspondences, fit anchors, verification cells, high-score cells,
   and attention weights cannot redefine, crop, dilate, or replace the masks.
4. A score is legal only when it is conditioned on the same sealed pair of
   connected masks. A and B cannot independently choose different objects and
   have their scores averaged afterward.
5. Occluded or background-looking cells may abstain through a dustbin or low
   reliability, but abstention does not remove the cell from target membership.

This is a structural contract, not a target mask annotation. The masks are
generated independently for every candidate from its reference and query
tokens; no human mask, box, point, polygon, or target-derived pseudo-mask is
read.

## 3. Inputs and access boundary

- Freeze the ColNomic backbone and its verified spatial token cache.
- Freeze the natural C128 membership produced by the versioned fold-local
  retriever. CW0 may not read D1 score, rank, slot, winner flag, or gap.
- Use the existing identity/group-disjoint inner folds.
- Before label join, all candidates use identical code and parameter sharing.
- The exact target label may enter only the post-forward retrieval loss and
  offline diagnostics.
- No identity-specific parameter, oracle candidate insertion, outer heldout,
  opened, sealed, Qwen token, home-file write, or human spatial annotation is
  permitted.

The shared trainable parameterization remains exactly the existing 4,357
parameter asymmetric rank-8 query/reference adapter, two reliability heads,
and one shared dustbin logit. A candidate head, slot embedding, identity table,
or global-image pair classifier is forbidden.

## 4. CW0 soft connected hypotheses

### 4.1 Result-blind seed enumeration

Every valid query grid cell is evaluated as an initialization seed. There is
no top-k, candidate-rank filter, label-conditioned seed, learned seed selector,
or result-driven pruning.

For a seed, construct `W_q` by canonical 4-neighbour BFS around that seed:

- maximum graph radius: 6 cells;
- maximum membership: 64 cells;
- queue order: `(graph_distance, row_major_index)`;
- boundary clipping only;
- minimum membership: 8 cells.

All cells admitted before the fixed cap remain members. The resulting mask is
saved and independently checked as one exact 4CC.

The adapted query-to-reference soft correspondence predicts a continuous
reference centre for the seed. The centre is canonicalized at `1e-10`, then
mapped to one reference cell. `W_r` is generated by the same radius-6,
maximum-64 canonical BFS rule on that candidate's reference grid. The centre
operation is detached from discrete membership selection; gradient flows only
through the subsequent soft correspondence and evidence, never through BFS,
rounding, or mask membership.

A seed with high dustbin probability is not deleted. Its hypothesis remains
available with weak/negative evidence and the exact H0 alternative.

### 4.2 One shared footprint, two cross-fit directions

The complete `W_r` uses the frozen 4x4-cell macro-tile checkerboard A/B split.
For each single shared `(W_q,W_r)`:

- A cells fit a ridge-regularized weighted affine map; B cells verify it;
- B cells fit an independent weighted affine map; A cells verify it;
- fit and verification endpoints are exact-disjoint in each direction;
- both directions refer to the same complete membership masks;
- neither direction may search for a new patch, centre, window, or footprint.

The affine fit uses reciprocal soft correspondence mass inside the sealed
window. It is continuous and ridge-stabilized so a weak positive still receives
gradient. Mass, effective-match, two-dimensional covariance, entropy, cycle,
and dustbin terms provide a differentiable anti-collapse barrier; they do not
hard-delete the positive during CW0 warm-start.

Each held-out cell contributes signed candidate-specific evidence from
reprojection, reciprocal return, cycle, dustbin failure, and its explicit
query/reference reliability. Reliability must multiply the evidence; storing
it only as a diagnostic is invalid. A zero-return cell contributes cycle
failure, never zero cycle error.

Candidate score is the fixed-temperature normalized log-mean-exp of all
result-blind connected-window scores plus one exact H0. It cannot read a global
pooled embedding, D1 value, candidate rank, seed rank, or number of legal hard
H1 slots.

## 5. Natural supervision

For each train-fold query, use the exact target reference already present in
its natural C128 and all 127 different-identity natural rivals:

\[
L_{rank}=\log\left[1+\sum_{g\ne y}
\exp\{(G_g-G_y)/\tau\}\right].
\]

No per-step detached strongest-rival selection is used. Every positive,
including a raw-H1 miss and a currently correct D1 example, provides gradient.

Training-only candidate-binding and spatial controls use namespaces disjoint
from the frozen evaluation controls and require the correct direction:

\[
L_C=\operatorname{softplus}(\delta+G_y^C-G_y),\qquad
L_P=\operatorname{softplus}(\delta+G_y^P-G_y).
\]

For the 4,724 legal same-canonical-reference multi-view episodes
`q1 -> r <- q2`, compare reference-side reciprocal-mass support and composed
`q1 -> r -> q2` closure only where both paths retain non-dustbin mass. Occluded
cells may abstain. The loss must prefer the real common reference to a
shape-matched wrong reference and a spatially permuted reference.

The once-frozen objective is:

```text
L = 1.00 L_rank
  + 0.25 L_C
  + 0.25 L_P
  + 0.50 L_crossview
  + 0.10 L_noncollapse
```

Each term is normalized before weighting. The weights, seed, temperature,
margin, optimizer, schedule, clipping, and update budget must be written to a
machine-readable contract before any natural target-join training run. They
must not be scanned on the 32-query endpoint.

## 6. Controls and anti-shortcut requirements

Required matched arms:

- `RAW`: frozen raw ColNomic local representation;
- `COMMON/NOREF`: same capacity with reference-local content replaced by a
  shape-matched common value;
- `NOCOORD`: same capacity without coordinate/reprojection information;
- `NOCROSSVIEW`: same capacity without the natural multi-view term.

Required invariants and destruction controls:

- joint candidate reorder equivariance;
- real target score strictly above train-C and train-P during learning;
- frozen evaluation C and P use separate maps/namespaces and reduce the heldout
  increment;
- a single patch, disconnected islands, a line, uniform centre, or all-dustbin
  state cannot authorize connected target evidence;
- changing the complete target label after the prejoin forward cannot change
  any seed, mask, transform, score, or hash;
- all-zero evidence remains exact H0 independent of seed/window count.

## 7. Staged gates

### E0 — synthetic engineering and learnability only

Use connected affine, occlusion, no-match, two-object, near-rival, disconnected,
and permutation fixtures. Require:

- exact single-4CC membership on both endpoints;
- removing the unique 4-neighbour bridge makes the hypothesis illegal;
- seed/fit/verification rows cannot replace membership;
- correct connected candidate beats a near rival, COMMON, C, and P;
- a zero-return interior cell lowers cycle response and score;
- reliability scales held-out evidence exactly;
- every trainable scalar receives finite gradient and one update changes the
  intended score/loss;
- repeated replay and candidate reorder meet the existing exact/`1e-7`
  contracts.

Status: `CW0_E0_READY` or `CW0_E0_ABORT`. No scientific claim.

### S0 — two-query natural plumbing

Run two optimization-role queries only. Require finite scores/losses, all 128
candidates, nonzero target/rival gradient, exact access counters, and no hard-H1
eligibility dependency. This stage does not require retrieval success.

### P32 — fixed proposal-recall screen

After the adapter is trained without using the P32 evaluation identities,
freeze it and regenerate hard target-free connected proposals with the strict
geometry contract. Only then join labels. Require all of:

- target has at least one legal connected H1 on at least 26/32 queries;
- raw baseline is recorded as 7/32 and the adapted arm is strictly higher;
- every legal target H1 has one exact 4CC at both endpoints;
- main target-vs-rival local score and target proposal rank beat RAW and COMMON;
- frozen evaluation C and P reduce the real increment;
- no single-patch/disconnected target H1 and no outer/opened/sealed access.

Failure status: `CW0_PROPOSAL_RECALL_NO_GO`. Do not change radius, cap, pooling,
temperature, loss weights, or thresholds on these 32 identities.

Passing P32 is the only point at which an approximately 0.8 conditional chance
for the larger connected proposal stage is defensible. It is not a scientific
ownership or retrieval GO.

### F — formal inner-OOF qualification

Only after P32 passes:

- run all five identity+group-disjoint inner folds;
- freeze each fold adapter before regenerating heldout proposals;
- require target connected-H1 coverage at least 0.85 overall and 0.80 per fold;
- require target-vs-natural-rival ranking, C/P, RAW/COMMON/NOCOORD/NOCROSSVIEW,
  fold-direction, and group-cluster uncertainty gates;
- only then authorize the all-heldout-cell connected-bin verifier and later
  D1 SWITCH/HOLD action experiment.

No opened or sealed endpoint is authorized by this contract.
