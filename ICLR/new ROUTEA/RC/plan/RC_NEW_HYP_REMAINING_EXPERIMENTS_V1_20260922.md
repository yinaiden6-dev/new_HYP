# new HYP：剩余实验与每项新增问题

2026-09-22。用户询问既有机制解释之后还应补哪些实验。本清单不重置旧结果，不将已做过的候选绑定、输入列消融、选点分解或成本改进称为新发现。仅前两项已具备执行授权文件及在途任务；后三项仍是后续实施顺序，本文不表示已提交。

## 已有结果直接复用

- ORIGINAL7 的 matched EVAL32、EVAL128：固定参数输入干预、同协议简单头重训、候选证据绑定及逐候选贡献。
- reference 权重改变匹配位置与幅度的分解、0337反转，以及统一/条件补偿的历史正负结果。
- H593 原五折的 COST4/COST1/CE、六列消融、learned ColNomic-only 候选统计头。旧内容头压缩 token 证据后训练小头，未训练逐 token 质量模块。
- GroZi/ISIC 等已有固定头迁移结果保持原头和原证据级别；RPC 按用户最新决定保留为诊断，不恢复为正式主结果。

## 1. 完成内部坐标精度干预（已提交）

NATIVE 与三档 refiner 输入坐标量化，内容 tokens、原 RAW C128、原头/同协议重训均受控。回答内部坐标精度改变是否通过 overlap 权重影响检索。最终 warp 事后取整作为评分依赖负对照。它不等于删去细特征、不测相对于真值的匹配误差，也不证明细粒度特征无用。

## 2. 完成评分算子拆解（已提交）

M/Q/R 三开关的八组合，加固定自由 MaxSim 命中位置，共九臂。保留完整 token 贡献与所有候选分数，固定头与重训共同报告。新增问题是同一 H593 协议下各操作对总体收益、损失及竞争的贡献，不是首次发现选点可能伤害身份比较。

## 3. 区分额外特征与两图匹配（下一组）

先采用 ColNomic 输出 token 端的低容量适配器。输入来源四臂：ColNomic 自身、RoMa 粗特征、细特征、粗+细。每种来源比较不使用 RoMa 匹配器的自由 MaxSim，与同样融合 tokens 加 RoMa 权重。原无适配器基线及旧内容统计头一起保留。

query/reference 使用共享模块；特征对齐、投影、训练预算和容量对照在训练前固定。报告参数差异和总计算成本，不能把投影容量增长归因于特征来源。读取 RoMa 训练过的 CNN 时名称为“无 RoMa 匹配器”，不称完全无 RoMa 预训练。

结果解释：无匹配器版本有效，支持利用额外单图特征；匹配版本仍有净增，支持当前匹配证据的附加价值；均以所测配置为限。失败不能证明对应信息绝对无用。若要定位完整 RoMa 内部细化器的独立贡献，再追加 matcher-only overlap 与完整 refinement 的阶段对照，不能由坐标量化结果代替。

## 4. 严格检索监督的纯 ColNomic token 质量模块（目标方法）

只读取原 ColNomic tokens 和允许的空间索引，通过两图相似度及局部分布学习候选条件的 token 权重，先保持编码器冻结。训练仅用原 query-reference 身份/正负关系，不加入 RoMa 图拟合或其他 teacher 辅助损失。

复用 RAW 与旧 learned ColNomic-only 统计头；新增等容量单图权重对照，与两图条件权重比较；保留原 RoMa 联合模型作为强基线。先根据步骤2结果选择作用于 query 汇聚、reference MaxSim 或整体质量的最小模块，并在本组训练前固定选择规则/结构。分析旧质量解释是否能转化为可学习的读取方式。

成功时分别陈述超过 RAW、超过旧纯内容头、接近/超过 RoMa 三个层级。编码器不变时只能称读取方式改善；表示改善需要另有改变 token 编码的受控实验。H593 已开发，任何结果都不称新盲测。

## 5. 插入位置与迁移（有前置结果再做）

若输出端适配存在稳定信号，固定同一特征来源比较输出128维端与视觉merger/LLM入口端；如需区分层级与算子，单独声明归一化规则不同，不用裸通道相乘。入口适配可能要求反向经过冻结主干，记录训练时间、显存、reference建库及每query延迟。

每个拟采用的新模型做 processed128 高基线回归；冻结全部选择后复用 GroZi/ISIC 做跨域复核，不再在这些数据上调参，明确它们已经打开。新模型的迁移不能继承旧固定头的确认资格。新编码器的全库召回实验另报，不能混记为原 C128 内的修复。

## 统一读数与留存

原自然 RAW C128、原身份/来源分组五折，593分母包含23个召回缺失。主COST1、辅助CE分开，保存全部臂，不凭heldout只报告最佳。报告正确数、MRR、相对RAW及原对应头的救回/损失、各组件效果与计算成本；预先固定少量训练种子，检查学习模块的稳定性，不挑种子。所有学习只使用当前训练折的检索标签，不读取留出标签来选架构或停止点。

中间文件按图像/模型SHA、fold、训练版本绑定：原/融合tokens、u/v或新权重、free/weighted命中位置、逐token贡献、全部127 logits及HOLD=0、参数和验证文件。沿用当前来源缓存，避免只存top1。

本地接口及更详细融合约束见 `RC_ROMA_FEATURE_COLNOMIC_FUSION_FEASIBILITY_20260922.md`。RoMa的匹配、overlap及设置接口亦可在[官方实现](https://github.com/Parskatt/RoMaV2)核查；替换输出不等于绕过产生输出所需的模块。
