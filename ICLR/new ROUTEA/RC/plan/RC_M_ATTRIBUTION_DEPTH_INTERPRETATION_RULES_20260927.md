# 两条归因分支的解释规则

2026-09-27。在新增上游完整组结果及下游交叉格结果汇总前记录；不改变任何封存实验、模型、候选或统计协议。

目的不是再次验证“M有效”，而是用明确反例排除一些更简单的计算解释。以下命题只约束被检验的固定计算接口，不是所有可能模型的唯一因果证明。

## 上游：哪些信息单独不足以解释输出

1. **P自身统计充分解释。** 循环平移保留P向量多重集、通道Gram及空间Fourier幅度；P开关为0时更是保持整个P张量不动。如果仅移动A/J仍改变M，则同一P可以在不同上下文中被解读为不同输出。不过单个移动对照还混入解码网格位置。
2. **context摆放项与P摆放项可以相加解释。** 对同一输出端点，若四格响应为`f(A,J)+h(P)`，则`[g000+g111-g001-g110]/2=0`。预定匹配对比非零意味着不能以这个可分离模型解释所测响应；不直接等于唯一语义配准。
3. **J/P交互与appearance背景无关。** 比较A固定和移动两种条件下的J×P交互。三阶差非零表明该交互依赖A背景；不把A移动当成移除A。
4. **共同平移是无效安慰剂。** 不能作此假设。完整DPT包含空间卷积、padding、resize及池化，111−000必须实测。匹配对照消除纯加性摆放项，不保证消除所有解码位置交互。

实际相加入口为`A1+J+P`，之后经过逐patch LayerNorm。其通道方差满足

`Var(A1+J+P)=Var(A1)+Var(J)+Var(P)+2Cov(A1,J)+2Cov(A1,P)+2Cov(J,P)`。

保持各项自身统计仍可能改变交叉协方差、总和方向及归一化方向。保存中间张量可以定位这类变化，但协方差或角度与M的相关性不能单独证明完整中介路径。保持总和相同的J/P补偿改变在该接口不可区分，因此不能识别唯一的J/P输入分解。

## 下游：为什么相对M改善不保证内容分差改善

实际冻结POST对每个候选分别计算：

`z(M)=gain*(log(M)-TRAIN_mean)/TRAIN_std`

`h'_i=h_i+scale*W_up GELU(W_down[LayerNorm(h_i),z(M)]+b_down)+b_up_scaled`

然后经过冻结投影、向量归一化和完整reference自由MaxSim。以上是实数示意；实际实现保留FP32适配器、BF16残差写回及原投影精度，不将该示意当作位精确代替。

1. **只读相对差距。** 若固定候选对的输出分差仅为`F=H(delta)`，固定delta而改变共同水平mu的两个条件效应都应为0。非零有限效应反驳此接口的差距充分解释。
2. **共同斜率的仿射读出。** 若每个候选都是`L_g=a*log(M_g)+b_g`且共享a，则在主log-M坐标中共同水平效应和交互均为0，差距效应为`a*Delta(delta)`。此假说只用主log-M分解检验；即使它成立，非线性的logit坐标变换也可能产生共同水平效应和交互，不能用logit的非零结果反驳它。主坐标实测违背时，该模型不足；其中共同水平效应也可能仅由两个候选的不同线性斜率产生，不能单独判定非线性，更不能直接断言唯一原因是GELU、投影、归一化或MaxSim某一项。
3. **绝对水平必然无益。** 原幅度LOCAL→GLOBAL同时改变mu与delta；只看总效应无法判定。本轮四格分别恢复二者，报告两个条件效应、交互以及对称分配。
4. **正M差意味着正内容差。** POST没有单调性约束。即使共同残差向量相同，对不同reference方向的角度作用也可不同。若分解显示mu负效应抵消delta正效应，可以解释当前反例；若不是，则如实报告实际路径。

在可微实数近似下，`F=f_t(mu+delta/2)-f_w(mu-delta/2)`，故`dF/dmu=f'_t-f'_w`，`dF/ddelta=(f'_t+f'_w)/2`。这仅说明两种响应不必相同；实际证据采用冻结模型有限交叉干预，不宣称测得这些导数。mu×delta交互可由两个独立的候选函数非线性产生，不代表新增跨候选attention。

## 统一解释与报告规则

上游检验的是“分布表示与内容上下文如何共同生成可区分的M”；下游检验的是“该标量如何结合具体内容转化为分差”。两个接口都可能需要条件配合，但不能因都存在交互就宣称数学等价或同一空间mask。

报告所有预定对照，包括反向与区间跨0的结果；方向重复先组内平均。上游9个已打开身份组；下游120张/45组与phase9重叠、分别报告。主log-M坐标21个非法格点保留清单；logit是整套预定敏感性分析，必须在相同合法样本集比较坐标差异。输入数值合法也不表示位于原TRAIN支持范围。

“穷尽”限于以上有限解释族、已保存接口与固定模型。若拒绝某个简单解释，只说它不能解释该组结果；不推广为普遍必要性、唯一视觉原因、外部验证或新准确率纪录。
