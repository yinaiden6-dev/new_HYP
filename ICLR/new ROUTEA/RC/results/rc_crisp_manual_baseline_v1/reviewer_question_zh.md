# 为什么训练一个七参数头，而不直接手填？

要回答的不是“能不能不用训练运行”，而是“学习这些系数有没有超过合理手工规则的可复现收益”。手填与训练都执行同一个 z = wᵀx + b，以及同一个正 logit SWITCH / 否则 HOLD；因此推理架构与部署复杂度相同，区别是系数从哪里来。

## 本轮直接检验

- 相同六个特征、相同 RAW winner、相同 127 个 challenger、相同 HOLD/SWITCH 阈值。
- 固定系数：六项等权（bias=0）；RAW 与其他五项平均等权（bias=0）。数值在新评分前冻结。
- 全零参数只检查严格退化回 RAW，不拿它当强免训练对手。
- 直接 visibility 评分、普通 image-token MaxSim、作者 CRISP 是补充的免训练评分对手；它们改变的评分路径与上述严格同头对照不同，必须分开解释。
- H593 上只使用已完成的按来源组隔离五折 OOF 训练头，不使用全 H593 拟合头冒充留出结果。RPC600 使用原来已冻结的 H593 训练头。
- 所有臂使用相同自然 C128。冻结编码器和 RoMa 已有预训练；此处“免训练”指不对当前检索任务额外拟合参数，不等于整个系统从未训练。

## 结果怎样决定论文表述

1. 若两种手工同头规则与训练头相近：如实报告，不能再把学习七参数作为性能所必需的条件。仍可讨论规则本身及部署选择。
2. 若训练头比手工同头规则准确率更高：报告具体救回、改错、配对净增和按来源组重采样区间。区间不能支持差异时，只能称观察到更高分，不能称可靠优于。
3. 若训练头在 H593 有优势但 RPC 没有：说明训练收益存在域限制，不能用开发面板差异替代迁移证据。
4. 若手工规则更好：承认固定规则优势，保留其冻结记录；不再修改手工参数来回追逐本轮测试成绩。

两种手工规则失败，只能排除这两个具体设定，不能证明“所有免训练权重都不可能”。这轮比较的是参数学习的经验价值，不是训练必要性的数学定理。

把原训练得到的数字手动抄进程序仍是原训练模型，只改变部署方式；人工反复参照测试标签改权重，也不能作为无监督免训练的独立证据。
