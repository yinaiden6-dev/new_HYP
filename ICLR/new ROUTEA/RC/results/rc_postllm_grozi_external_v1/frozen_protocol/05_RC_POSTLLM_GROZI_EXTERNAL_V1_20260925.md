# 内部 POST 模型的 GroZi480 冻结迁移：最终补充实验

用户授权：2026-09-25“然后补一个内部模型的外部数据实验就收口”。

只补这一组跨数据集验证，不新增优化分支。选用已公开使用过的 GroZi480 商品裁剪面板，原5533物理图库、自然C128和27个来源视频；480张全部计入，包括自然C128中缺少target的情况。该面板此前用于外部头评估，因此是固定源模型在已使用外部数据上的验证，不称未接触数据的新确认，也不承担全场景定位或分割IoU验证。

## 冻结模型

预先按固定编号选择H593 fold0 POST_REAL最终8轮模型（457个入池TRAIN，3656更新）；不比较外部结果选择折，不对五折参数平均，不重新训练全593。保留该模型适配器、INTERNAL3头、源TRAIN的log-M标准化、原未合并BF16投影和严格正logit才SWITCH的0阈值。它是一套固定单模型；不得把H593五折478/593当成这套模型的单次源评测成绩。

主臂POST_REAL；原RAW和无适配器的fold0 warm INTERNAL3为内容基线；同一POST_REAL推理时分别用constant条件、沿物理候选轴循环错绑M验证绑定依赖。constant意为标准化条件=0，不是M=0。源fold0的ADDITIVE4与PRODUCT5外部头作功能参照，全部参数冻结，不在GroZi选阈值或校准。

## 复用与执行

复用旧60个8图分片的原RAW排序、query/reference最终tokens、RoMa u/v和M。只补每张query一次冻结ColNomic前向，保存真实3584D完整序列hidden、image_mask、原生tokens、投影等价和原token核对。image_mask仅表示图像token位置，不是target mask。reference和RoMa不重新运行。

完整hidden缓存后，POST只经过小适配器与检索投影。为保持已验收BF16核的精确行为，本轮采集与回放在同一GPU任务完成。首个原分片8张验收后，剩余59个分片由12个短任务并行承接（每任务4–5个旧分片），避免为每张query重复加载大模型。每次10分钟，可从逐query/候选断点续跑，最多12次requeue；不自动新增训练。

所有预测保留128个内容分数、127 challenger logits、HOLD=0、candidate轴、输入和模型SHA。先完成并封存480张全部臂预测，后读外部标签，独立NumPy重算特征/动作，按27视频作配对bootstrap，报告R@1、MRR、rescue/break和候选召回。

## 收口标准

回答固定内部模型能否在源域以外有效利用真实M，并报告恒定/错绑的变化；内部模型不必超过外部模型。无论正负都保留完整结果，不因结果自动重训、改阈值或再选数据。结果进入统一论述与论文草稿后结束本轮补充。
