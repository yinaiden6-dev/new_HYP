# 后 LLM 内部 M：H593 全量扩展 V1

用户授权：2026-09-24「先把内部改造，从8扩展到全量」。

## 固定研究对象

扩展已完成的 POST_REAL：冻结 ColNomic 原骨干、检索 LoRA 和检索投影，在 LLM 输出 hidden 与检索投影之间训练质量条件残差适配器；保留 RoMa 真实 M。末端 INTERNAL3 只读标准化 RAW 差、适配后内容相对差、偏置，不直接读 M。不要求内部模型超过外部头才算有效。

全量定义为现有 H593，使用其原五折分组划分、ColNomic 自然 C128 和图库物理 reference 轴。最终每张 query 只计相应留出折预测一次；23张目标不在 C128 的图片仍进入593分母。此前各面板均已用于开发，本扩展是全量分组交叉验证，不称新的未接触确认。

## 三臂与固定训练量

- POST_REAL：原始真实配对 M。
- POST_CONSTANT：适配器内部标准化 M 恒为0。
- POST_SHUFFLED：在每张 query 的固定128候选轴上循环移位1位，训练与留出推理使用同一预定规则。
- 真实模型另外保留同参数、同头的恒定及错绑 M 推理干预，不重新拟合。

每臂每折独立从相同 seed17 和零输出残差初始化，16维瓶颈、残差尺度0.1、条件增益sqrt(3584)。只在该折候选内 TRAIN 上估计 log M 均值/标准差，训练该折 INTERNAL3 warmstart，并训练外部 ADDITIVE4/PRODUCT5 对照。不加载试点16张训出的头或适配器，避免跨折泄漏。

训练量冻结为8次完整 TRAIN 遍历（试点128更新/16张=8遍），每次更新处理一张 query 的完整C128；各臂相同query顺序、优化器和预算。沿用原COST1损失、FP64头及内容评分、BF16冻结投影的运算顺序。保持原学习率：adapter 3e-4、head 3e-2，weight decay 1e-3，梯度clip 1。不得按held结果选择步数或阈值。

## 缓存复用与一次补采

已有全部593张的M、RAW、自然C128、最终query/reference tokens。旧试点24张通过验证的postLLM hidden只读复用；补采缺少的569张query hidden。模型与processor版本沿用已通过的BF16/torchvision/sdpa版本。所有reference最终tokens复用，不重新编码reference、不重跑RoMa。

新增缓存必须保存实际LLM末端3584维hidden、完整序列image mask/attention mask与native tokens。128维最终token不能冒充LLM hidden。每图验证冻结投影回放、历史token轴及数值容差；失败图不进入训练。缓存不含折相关学习状态，可供各折三臂共享。

GPU采集按50片、最多并行50、accelerated、每片10分钟提交；先通过真实图工程验证再自动提交其余。训练按3臂×5折并行，使用短任务断点续跑。首个真实训练更新检验梯度、参数/优化器断点与恢复；通过后释放全部训练。根据实际资源情况可使用已授权dev分区，不把排队当科学失败。
