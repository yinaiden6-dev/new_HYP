# 是什么支持 M 的区分倾向：对应结构的受控归因

2026-09-24。按用户修正，问题不再停在“M有额外区分信号”，而是定位这种区分由什么输入性质产生。本报告不计算纠错数，不评估新的检索模型，不调用外部头或内部适配器；直接研究 RoMa COARSE 的 M。

## 1. 这次真正被隔离的性质

之前 P 置零同时移除了对应分布的幅度和位置成分，不能由此把作用归给“集中度”。已授权范数／相位实验的预定主面板8张、8组现已完成每张全部128候选，合计1024对。1张target不在池内，7张用于target与固定错误候选的分差。另3张按原纠错选择的病例尚未纳入本分析，不能替代主面板。

本次固定 query/reference 图像、单图表示、原生两图上下文 J、预测头参数，只改变软对应位置分布编码 P。比较：

- **一致平移 GLOBAL：** 所有 query patch 指向的位置分布一起平移。
- **不一致平移 LOCAL：** 不同 query patch 的位置分布按固定平衡符号场向相反方向平移。

两者均保留每个patch的P范数和每个傅里叶频率的幅度；正负平移成对平均后，GLOBAL与LOCAL的扰动能量相同。所有轴和正负方向都按预定规则平均，不选最好或最差的干预。

因此，这比“删掉P就变差”更具体：在集中度和扰动幅度得到控制时，检验不同patch之间的位置关系是否仍参与 M 的区分。它不是从图像中删除真实物体几何，也没有改变 J 中可能已有的位置表示。

## 2. 固定内容对手，直接检查 M 的身份对比

错误对手固定为原始自由 ColNomic L 最高的错误 reference，不使用任何干预后的 M 选择对手。度量为：

`C_M = log M_target - log M_fixed_wrong`。

它去除了同一 query 所有候选一起乘同一尺度的影响。只把候选整体分数压低而不改变相对证据，不会产生这个对比量的变化。

| 干预对比 | 7个组的平均 C_M 变化 | 探索性组bootstrap95%区间 |
|---|---:|---:|
| GLOBAL减原生 | +0.003176 | [−0.005427,+0.011724] |
| LOCAL减原生 | −0.023420 | [−0.044082,−0.008180] |
| LOCAL减GLOBAL | **−0.026597** | **[−0.042368,−0.012411]** |

7张的 LOCAL−GLOBAL 均为负。换成“与target内容分数最接近”的固定错误对手，均值为−0.025242，区间[−0.041989,−0.010614]。0.005的严格内容近分带在这8张中仅覆盖1张，因此不能用该小面板声称完整复现了H593近分统计。

这是新获得的受控来源证据：**在当前模型和这组样本中，P的相对位置排列及其与固定上下文的配合，对 M 的区分有贡献；仅保留其集中程度不足以保留该部分作用。**

## 3. 作用不是“把所有正确分数拉高”

相对GLOBAL，LOCAL使target的log M平均上升+0.017624，同时使所有错误候选的平均log M上升+0.043815。固定最强内容错误对手上升得也更多，所以target优势减小。

这提供了更具体的作用方向：**原生对应结构的一部分作用体现为约束混淆候选的支持，而不是普遍增加输出。** 不能用“P越集中，M就越高，因而更正确”解释这一结果；范数保持时仍存在区分变化。

幅度也可能有作用，但尚不能定主次：AMP_FLAT将P范数统一后，最强内容对手的平均C_M变化为−0.167389，区间[−0.380991,+0.017774]；AMP_PERMUTE保留幅度直方图、打乱幅度与patch绑定，均值−0.053404，区间[−0.167425,+0.037237]。两者在主对手定义下区间均跨零。改变幅度和改变相位的干预剂量不同，不能用这两个均值的大小给两种信息排贡献比例。

## 4. 对应分布的作用还依赖上下文

复用原common41全部候选的已有入口干预，38张target在池内、28组。同样固定“自由内容最高错误reference”，直接计算COARSE的 C_M，完全不经过COST1。

| 固定其他直接输入时的对比 | 平均 C_M 变化 | 探索性组bootstrap95%区间 |
|---|---:|---:|
| 保留P，加入J直接输入 | +1.297566 | [+0.938551,+1.634762] |
| 保留J，加入P直接输入 | +0.693173 | [+0.400169,+0.972825] |
| J直接输入置零时，加入同一个原生P | −0.078790 | [−0.138693,−0.019276] |
| J×P的条件对比差 | +0.771963 | [+0.450526,+1.066950] |

这部分是旧干预的新对齐读出，不冒充新的干预数据。P本来由原生J派生，J置零仅发生在预测头入口；它不表示P来源中的J也被删除。输出的非线性也参与这些条件对比。因此这里能说明**预测头如何在上下文条件下使用对应编码**，不能把两者解释成独立信息源的贡献相加。

结合范数／相位控制，目前更具体的工作解释是：**两图上下文使预测器能够结合软对应的分布形状与相对排列，形成对不同候选有区别的匹配支持；一致的对应结构还参与约束错误候选的过高支持。** 尚不能简化为某一个熵、某一种几何误差或一个单图特征范数。

## 5. 为什么 RoMa 有能力提供这种证据

RoMa v2的confidence目标是两视图的共视性；overlap监督来自深度一致性或光流循环一致性，使用逐像素二元交叉熵。其预测器结合两图交互特征和softmax对应位置编码。该预训练目标提供了学习“内容是否支持跨视图对应”的来源，区别于只读取最高内容相似度。[RoMa v2原文，第1、3节及附录D](https://arxiv.org/html/2511.15706v1)

这是对能力来源的文献及实现依据，不等于已经证明药盒上的区分全部来自几何监督，也不排除DINO表示、训练分布偏置或其他匹配器能提供同类证据。本项目的retrieval-only指下游适配与头的身份监督，不能将预训练RoMa的监督来源改称没有几何监督。

## 6. 与外部干预、内部改造的连接

本次定位的是链条前半段：

`两图上下文 + 软对应的分布／相对排列 → 候选间不同的匹配支持 → M的相对证据`。

下游已经分别验证的传递路径是：

- 外部头显式读取M差异及内容证据；M特征为`tanh(0.5 log(M_g/M_h))`（忽略极小epsilon）。
- 当前POST小面板的表示改造主要把log M转成共享表示方向的幅度，再成为内容分差；TRAIN拟合的标量响应在已打开PROBE8能近似解释这种分数变化。

可以统一到：**先利用配对关系判断哪些内容匹配值得得到支持，再把候选相关的支持差异传给身份比较。** 上游可以使用位置关系形成判断，下游却不必重新执行定位或强迫内容只读某个指定坐标。

这不是把“质量”换一个名字：对应输入性质、M相对证据和下游表示／评分分别有不同的干预或回放依据。但本轮没有把所有相位干预的M再送入同一个POST适配器，因此不能宣称已经完成端到端同一干预的完整中介归因。现有证据支持链条分段；原COST1和POST仍是不同模型与数据范围。

## 7. 限制和产物

相位平移仍可能改变输入相对训练分布的位置、绝对坐标约定和与固定J内容的对齐；GLOBAL是等能量控制，不能消除全部分布外因素。只有7个有target的预定组，且COARSE不是完整HR1。因此可以归因出一个具体成分，不能宣布已获得可推广至所有数据的唯一根因。

保留所有12臂和逐候选 M，没有按准确率或显著性挑选配置。5000次组bootstrap为探索性，未作多重比较校正。
