# new HYP：匹配质量为何能纠错，内部路径究竟做了什么

日期：2026-09-24。本文把既有上游干预、新增真实 M 主效应分解与内部表示回放连成解释链。它不是新的全量训练结果，也不改变原 COST1 主模型。

## 需要解释的对象

“RoMa 增加了关注度”“M 有用”“内部也可以提高一张”都不足以描述完整机制。应分别回答：

1. M 的预测量是什么，它与身份相似度有什么区别？
2. M 中的收益是否只来自 reference 普遍容易被匹配，而非对当前 query 的证据？
3. 有用的部分如何通过实际评分与归一化形成候选差距？

不能用“ColNomic 信息不够”作统一答案。当前 MaxSim 或小读出头无法恢复一种关系，不等于整个冻结 token 集合在信息论上不含该信息。蒸馏失败也不能完成这个证明。

## 上游：可匹配性与身份特异性是两个预测对象

RoMa v2 将置信度定义为两图中场景点的共同可见性；理想情况下共视点为 1、遮挡点为 0。它的粗 matcher 将单图特征、两图 Transformer 输出和匹配位置嵌入送入预测头。它不是直接训练药盒身份正确率的分类器。[RoMa v2 原文](https://arxiv.org/html/2511.15706v1)

本地源码 `third_party/RoMaV2/src/romav2/matcher.py` 对应的 head 输入为单图特征 + 两图交互特征 + 匹配位置嵌入；项目从 confidence 的 sigmoid 网格汇聚双侧质量，再以 M=sqrt(mean(u)mean(v)) 进入身份决策。因此 M 应被称为候选条件的匹配支持量，而不是正确身份概率。

内容检索的自由 MaxSim 则逐 query token 取最高相似度，再平均。这个读出会把不同匹配结构压成相同分数，例如相似度矩阵 `[[0.7,0],[0.7,0]]` 与 `[[0.7,0],[0,0.7]]` 的平均 MaxSim 同为 0.7，但前者两行依赖同一 reference token，后者覆盖两处。这是读出不能辨认全部匹配结构的例子，不是 ColNomic 全部 tokens 缺信息的证明，也不说明 RoMa 必然正确区分这两个构造。它明确了匹配支持可能补充哪类读出缺口，而非预先把缺口归咎于编码器。

从统计决策看，对身份正确事件 Y、原内容/候选先验证据 Z=(RAW,L)，联合后验的对数优势可写为原后验对数优势加上 `log p(M|Y=1,Z)/p(M|Y=0,Z)`。这是 Bayes 公式，不是本文新定理。它说明即使 M 不是身份概率，也可能通过条件分布差异贡献身份证据；并不要求直接相乘 M×L，更不保证用有限数据学习的小头达到最优。是否存在可泛化的增量，必须由固定对照判定。

现有固定模型干预已经把这条上游路径接到纠错：

- 41 张共同缓存、原折冻结 COST1：原 35/41，RAW 32/41。质量预测头入口的两图交互置零后，仅替换 M 就回到 32/41，原 3 次纠错消失；删除后续置信度增量仍为 35/41。单图入口置零仍保留纠错，但两图特征仍携带外观，不能说外观无用。
- 55 张、32 组、原冻结 COST1：原 46/55、RAW 41/55。reference 低通只改变 M，ColNomic 内容完全保持原样，仍使原 5 次纠错消失。query 打乱后平均 M 上升约 23%，但候选区分间隔下降；质量不是越大越好。
- 70 张已打开子集：真实粗阶段提前退出的冻结头仍为 56/70、RAW 50/70。它支持这批纠错不必依赖后续精细化，不证明所有场景的精细对应无用。

这些是固定网络的条件干预，含输入分布变化；不能改写为所有架构的必要性定理。对应报告：[41 张通路](REPORT_H593_SUBSET41_FROZEN_PATH_INTERPRETATION_20260923.md)、[55 张视觉干预](REPORT_H593_VISUAL55_FINAL_INTERPRETATION_20260923.md)、[70 张提前退出](REPORT_H593_COARSE_EXIT_V1_20260923.md)。

## 新增检验：reference 先验是否解释了大部分收益

这个问题不能只靠候选错绑回答，因为错绑同时破坏 reference 主效应与配对差异。历史 [R5V6 全图库 STOP](REPORT_R5V6_ROMAV2_FULL_GALLERY_SOURCE_E0A_STOP_20260905.md) 已经发现 reference hubs；本轮不重开那份实验的保护标签。

新检验在 H593 原五折、自然 ColNomic C128 上进行。每折仅使用 TRAIN 的无标签 M 拟合固定 2000 次 ALS：log M=mu+a_query+b_reference+residual；reference 使用物理图库行键。保持已有 COST1 PRODUCT5 头、RAW、自由内容及 HOLD=0 不变。

| 冻结头读取的质量 | 正确/593 | 相对 RAW 救回/损失 |
|---|---:|---:|
| RAW | 426 | 0/0 |
| 原始 M | 481 | 57/2 |
| 仅 TRAIN 估计的 reference 主效应 | 427 | 2/1 |
| 原始 M 除去 reference 主效应 | 481 | 57/2 |
| 恒定 M=1 | 426 | 0/0 |

去 reference 主效应与原始 M 并非逐图等价：相对原始 M 为 5 救/5 损，但保留原 57 次救回中的 52 次；reference 主效应单独未保留其中任何一次。所有 570 个候选内 target 的 reference 都在相应 TRAIN 候选边中出现过；全部 held 候选边中 3.51% 未见，按冻结规则回退。

为排除未见或极低频参考主导，另在 target、RAW winner、原最高挑战者均有至少 5 次 TRAIN 观测的 385 张上比较：RAW 280，原 M 314，reference 主效应 280，去主效应 316，恒定 M 280。去主效应保留这部分原 34 次救回中的 31 次。这个分层是条件性检查，不代替全 593 结果，也不消除所有主效应估计误差。

独立程序从原始 M/L/RAW 和封存折头重算 225,933 个原 logit，最大误差 1.78e−15，动作完全一致；新增恒定 M 对照全部 HOLD。[独立核算与支持度分层](../results/rc_h593_mass_main_effects_v1/independent_constant_degree_audit/report_zh.md)

**现有结果不支持把主要收益归结为这个已估计的 reference 普遍可匹配先验。** 但剩余量仍含非线性单图因素、采样偏差和估计误差，不能直接改称纯粹几何交互或真实身份信号。冻结头实验也不评价各变体重训后的最优能力。

正数、忽略 epsilon 时，实际 dM=tanh((log M_g−log M_w)/2)。同一 query 的共同尺度抵消，而 reference 差异与配对剩余差异进入竞争。实际程序保留原 epsilon，各折最大统一缩放 feature 误差约 1.2e−10，零个决策变化。这是已有尺度性质与新主效应实验的连接，不是新创数学定律。

可复用证据：[原始分解结果](../results/rc_h593_mass_main_effects_v1/result.json)、[程序](../programs/analyze_rc_h593_mass_main_effects_v1.py)。

## 下游：为什么“表示变了”仍不等于“找对了区域”

POST_REAL 在 LLM 后、检索投影前注入 M。它没有改变 LLM attention，也没有从 scalar M 获得某个 patch 的位置标签。已验证的新纠错来自内容分数改变：POST 内容接回 PRE 旧头仍 5/8，而 PRE 内容换 POST 新头仍 4/8。

但需要再分开两种计算：所有 patch 共用的质量方向，与依赖各 patch 内容的响应。对归一化 token z=p/||p||，共同扰动 d 的一阶效应是 (I−zz^T)d/||p||。即使 d 对每个 patch 相同，归一化后的 token 变化也不同。因此仅观察不同 patch 的向量或热图变化，不能证明学会了局部注意或空间定位。

新增 CPU 回放保持真实 hidden、冻结投影、自由 MaxSim、头及候选不变，分别保留共同响应或 patch 剩余响应，并固定原恒定 M 的命中位置检验是否需要重新选点。全 24 张、3072 对候选已完成。

| 同一封存 POST_REAL128 的回放 | TRAIN16 | 已打开 PROBE8 | 与真实 POST 的身份决策差异 |
|---|---:|---:|---:|
| 内部 M 固定为训练均值 | 8/16 | 4/8 | 5/24 |
| 真实 M 完整响应 | 10/16 | 5/8 | 0/24 |
| 只保留跨 patch 共同响应 | 10/16 | 5/8 | 0/24 |
| 只保留 patch 零均值剩余响应 | 8/16 | 4/8 | 5/24 |
| 真实 M，固定恒定条件的 reference 命中 | 10/16 | 5/8 | 0/24 |
| 共同响应，并固定 reference 命中 | 10/16 | 5/8 | 0/24 |

这不是只看正确数相同：共同响应加固定命中复现了全部 24 张的最终身份选择，保留两张 TRAIN 救回与一张 PROBE 救回。零均值剩余响应单独没有保留这些纠错。它支持这个端点的特定计算路径足以保留行为，不证明其他模型也无需 patch 特异响应。

独立核算从保存的逐 patch 输出重算全部 21,336 个 logit，最大 L 差 2.22e−16、logit 差 7.11e−15；重组臂与真实臂的保存 patch 分数、L 和 logit 均相同。CPU/GPU 最大 L 差约3.25e−5、logit差约0.001069，全部24张动作一致，不能称CPU重演为GPU位级相同。hidden/token误差上限来自生产程序测量，独立核算不重复完整投影。[24张独立报告](../results/rc_postllm_m_signal_decomposition_v2/independent_decomposition_audit/report_zh.md)

共同方向仍是 d(query,M)，不能因此说它仅依赖 scalar M。另一个对照只用 16 张 TRAIN 的特征构建共享 M 响应函数 d_T(M)，用于未参与此函数构建的 PROBE8；下文单独记录结果。

### TRAIN共享响应：是否必须为当前query生成特有方向

此项现已完成全部8张probe。固定原训练得到的适配器，只在TRAIN16上收集每个patch进入16维GELU瓶颈的内容项；对每个实际M逐patch计算非线性响应，再先在query内平均、随后对16个query等权平均，得到共享响应函数d_T(M)。不利用probe的特征或标签拟合这个函数，不重新训练任何参数。

| probe8路径 | 正确/8 | 对RAW救回/损失 | 与原POST身份选择差异 |
|---|---:|---:|---:|
| 原POST真实M | 5 | 1/0 | 0/8 |
| 当前query自己的理想共同响应 | 5 | 1/0 | 0/8 |
| TRAIN共享响应d_T(M) | 5 | 1/0 | 0/8 |
| TRAIN共享响应d_T(M)，并固定原匹配位置 | 5 | 1/0 | 0/8 |
| 同一POST模型内部条件恒定 | 4 | 0/0 | 3/8 |

因此，在这一端点和probe面板上，**不需要当前query特有的M响应函数，就能保留全部身份选择及那次纠错**。仍然保留当前query的恒定条件内容底座，检索投影、每个patch归一化及与reference的内容比较也都存在。共享函数只替代M引起的增量，不是删除query内容，不是M单独识别身份；同一函数随M改变输出向量，也不是对所有候选加同一个常数。

理想共同响应对照用于衔接实际BF16差分与TRAIN共享函数；二者可含FP32运算顺序及舍入差异，不能把所有数值差单独归因为BF16量化。这里只评估了1张TRAIN工程样例和8张probe，没有声称TRAIN共享函数已复现全部16张TRAIN成绩。[完整共享响应结果](../results/rc_postllm_train_pool_common_v2/summary.json)

最终联合独立验收已通过：核对4,224个候选证据文件，重算29,337个logit，最大误差7.11e−15。cefdinir用TRAIN共享响应时target logit为+0.36148178；固定原匹配位置后为+0.30506260，仍然正确切换。共享函数的TRAIN来源、128个M条件、逐patch分数和最终动作均核对。[完整独立报告](../results/rc_postllm_m_signal_decomposition_v2/independent_decomposition_pool_audit/report_zh.md)

### 共同方向为什么能够改变身份分差

令恒定条件下某个 patch 经过检索投影的向量为 p_i，M 造成的跨 patch 共同 hidden 位移为 d，冻结投影的线性部分为 W。在忽略有限精度舍入的理想运算中，新的单位检索 token 为：

\[
z_i(M)=\frac{p_i+Wd}{\sqrt{\|p_i\|^2+2p_i^\top Wd+\|Wd\|^2}}.
\]

同一个 Wd 对不同 patch 的影响不同，因为 p_i 不同；它对不同 reference token 的点积也不同。即使固定每个 patch 原先命中的 reference token，也可能改变 target 与错误 reference 的相对分数。它不是给每个候选统一加一个常数，也不等于把原 token 同乘一个正标量——后者经过 L2 归一化会抵消。

该公式是标准归一化向量代数，不是新提出的定理。真实执行保留 BF16 投影和 FP64 最终归一化；定量判断以保存的逐 patch 分数与动作回放为准，不能用一阶近似取代验证。

这里要检验的具体命题是：在这个训练得到的 POST 模型中，M 是否主要通过共同方向调制既有内容相似度，而不必通过 patch 特异响应或重新选择匹配位置来纠错。这给出了可被对照推翻的解释，而不只是“编码器学会使用质量”。TRAIN 共享方向对照还进一步检验，这种 M 响应方向是否必须针对当前 query 重新生成。

### 两条实验的结论不能合并成未验证的因果链

H593 主效应分解使用外部 COST1 PRODUCT5，POST 使用 TRAIN16/PROBE8 的内部适配器与三参数头。前者限定外部质量收益的来源解释，后者定位另一个小模型如何把 M 变成内容分差。H593 原来的 55 个净增益不是由 POST 适配器产生；本轮也没有证明去 reference 主效应的剩余部分就是 POST 共同方向编码的那部分信息。

本文的“校准”指候选分差与接受动作的学习调整，未检验概率校准，不将 M 或 head 输出解释为已校准的正确概率。

## 当前贡献应如何加深

可以建立的研究问题是：**由匹配任务学得的共视支持，如何在保留自由身份内容搜索的条件下，成为候选间可用的校准证据；这种作用在表示中究竟需要哪些自由度。**

一个可以由这些对照共同支持、但必须保留各自证据范围的认识是：**候选绑定与位置绑定是两回事。** 对某个 reference 的匹配支持必须与该候选相符，身份内容却不必服从匹配器指定的单个坐标。下游可以保留整体支持和自由内容搜索；内部端点也可以用 M 改变既有匹配的分差，而无需重新选择匹配位置。

这里有三种更具体、可被数据区分的解释，而不是一句笼统的“联合有效”：

| 待检验的简单解释 | 如果它足以解释当前结果，应观察到什么 | 本轮及既有结果如何限定它 |
|---|---|---|
| 主要只是偏好某些本来易匹配的 reference | 估计出的 reference 主效应应复现大部分原纠错 | H593 的此项估计仅427，原57次救回保留0；去该项仍481、保留52次 |
| 有效一定来自重新找到或强调局部匹配点 | 去局部重加权后应无法恢复，内部固定旧命中应失去本次纠错 | H593简化算子重训恢复总数481；POST共同响应且固定旧命中复现24张身份决策 |
| POST新增纠错只是训练出更激进的末端头 | PRE内容换成POST头也应得到同一纠错 | PRE内容配任一头均4/8，POST内容配任一头均5/8；固定POST头的中间分数路径直接跨过零阈值 |

这些结果分别排除特定实现与协议中的解释，不能升级为对所有先验、局部机制或读出函数的排除。POST适配器使用固定约59.87倍的条件增益与16维瓶颈，共同响应占优势也受该设计影响，不外推为所有内部条件化模型的自然规律。

投稿贡献的实质应落在这些能够反驳替代解释的发现，以及保留证据、放开坐标约束的具体接口和跨数据集验证。共享向量的归一化代数、匹配验证思想、FiLM条件化结构本身不是本文新发明。H593的大样本外部路径结论与POST的小面板内部机制发现分开陈述；是否具有足够的主会新颖性，仍取决于这种发现相对已有工作的分量，不能仅用增加实验数或换名称保证。
