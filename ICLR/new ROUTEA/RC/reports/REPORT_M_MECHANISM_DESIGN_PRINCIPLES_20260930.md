# M 机制理论:判别信息、使用方式、设计原则

本文不新增实验。全部数字来自已冻结结果的离线重算与已有报告的交叉对照;重算脚本
`programs/analyze_rc_m_upstream_offline_recompute_v1.py`,输入
`results/rc_m_upstream_event_closure_v1/result.json`(38 行 × 全 arm,486 个世界决策)。
无新训练、无 GPU、无新提交。

本文的组织方式是三问一答,并在每一节末尾给出**成立条件 / 失效条件 / 支持证据**。
凡未闭合的,写在 §5,不写进设计原则。

## 0. 先更正两处此前的内部结论

**(1) 撤回"共同水平与选择性共线、导致归因不可识别"。**
这个说法错了。共同水平对所有候选加同一常数,在任何 target 减 wrong 的对比里
**自动约掉**。离线重算(§A)证实:

```
raw  = logM_effect[target]     - logM_effect[strongest_wrong]
cent = centered_effect[target] - centered_effect[strongest_wrong]
max |raw - cent| over all arms/cohorts = 0.000e+00
```

因此 `target_vs_fixed_native_wrong` 从一开始就是免疫共同水平的,它跨 0 不是被共同水平
污染,而是一个**真实的负结果**。`candidate_common_level` 是诊断量,不是混淆量。

**(2) 撤回"POST 是增益过大的小头,压增益即可把 8 拉回 10"。**
反证见 §3.2:POST/外部的响应比**不是常数**,在 1.5×–9.4× 之间随扰动类型变化;
且 POST 的共同水平贡献**跨 edge 变号**(+1.96 / −0.59)。标量增益修正在数学上
不可能同时修好两端。

## 1. 第一问:新增的判别信息是什么

### 1.1 可陈述的正面性质:target 稳定位于候选场的头部

去掉共同水平后,用秩统计量(无标度,免疫共同水平,也免疫"谁是最强"的选择):
`frac` = 127 个错误候选中,中心化效应超过 target 的比例。0.5 表示无选择性。

| 干预 | frac | 95% CI | z | centered_sd |
|---|---:|---|---:|---:|
| AMP_FLAT | 0.099 | [0.023, 0.211] | **+1.91** | 0.186 |
| AMP_PERMUTE | 0.171 | [0.088, 0.294] | +1.10 | 0.119 |
| GLOBAL−LOCAL | 0.209 | [0.128, 0.310] | +0.88 | 0.032 |
| matched_alignment | 0.332 | [0.213, 0.473] | +0.47 | 0.031 |
| P_only_moved | 0.668 | [0.531, 0.785] | −0.47 | 0.032 |
| P_fixed_move_AJ | 0.740 | [0.619, 0.849] | −0.81 | 0.036 |
| grid_control | 0.845 | [0.678, 0.969] | −1.17 | **0.012** |

**target 稳定位于候选场前 10–20%**,9 个 component 方向一致。这是 RoMa 相对
ColNomic 新增的判别信息的可测形式:它不是"更高的相似度",而是**在把候选场整体
重排时,正确身份被系统性地留在头部**。

### 1.2 负面性质:赢平均,不赢最强

同一批数据,`target_vs_strongest_wrong` **全部跨 0**(GLOBAL−LOCAL −0.00915
[−0.0256,+0.0077];AMP_PERMUTE −0.05873 [−0.1811,+0.0606])。而
`target_vs_mean_wrong` 显著为正(+0.0269 / +0.1299,8–9/9 组同号)。

两者不矛盾,是分布形状的两个读法:**弱候选被压垮,最强混淆者没有**。127 个候选中
排前 10% 仍意味着约 12 个候选在前面,最强混淆者就在其中。

这正面回答了"为什么原 ColNomic 没充分利用":ColNomic 的检索评分是**逐候选**的内容
相似度,不含"两张图之间的对应关系"这一项;RoMa 计算的是关系量,它带来的是
**对候选场的整体重排能力**,而这种能力在平均意义上强、在尾部(最强混淆者)不足。

### 1.3 方法学警告:秩统计量不能单用

`grid_control` 是零效应对照,它的 frac=0.845、CI 排除 0.5,看起来"强选择性"。
但它的 centered_sd 只有 0.0124,是所有 arm 中最小的。**秩是无标度的,一个微小
但方向一致的位移会被读成强效应。** 逐图看:11 张中 7 张 frac ≥ 0.93,而
centered[target] 只有 −0.006 至 −0.026。

> **原则 A(指标选择)**:报告秩选择性时必须并列 z 或幅度门。
> 成立条件:|z| ≥ 0.5 且 centered_sd 不是同批 arm 中的最小值。
> 失效条件:小 sd 的零效应对照;此时秩显著是假阳性。
> 证据:grid_control frac=0.845 / z=−1.17 / sd=0.0124(最小),对比
> AMP_FLAT frac=0.099 / z=+1.91 / sd=0.186。

## 2. 第二问:这些信息怎样变成纠错

### 2.1 外部头:比值不变性是**精确**的

已有四格/Shapley 分解中,外部两头的共同水平贡献在**所有** scope 下都是 0
(数量级 1e-10 至 1e-17,即数值零):

| head | 共同水平贡献 | 相对差距贡献 |
|---|---:|---:|
| NATIVE7 | 0.0000000 (全 scope) | = 全部效应 |
| M_FREE | 0.0000000 (全 scope) | = 全部效应 |

这与 §A 的 `raw == cent` 是同一事实的两条独立测法(一条来自 Shapley 分解,一条来自
逐候选中心化)。外部头**只读候选间相对证据**,这一点已闭合。

### 2.2 内部 POST:共同水平贡献**跨 edge 变号**

同样的分解,POST 的共同水平贡献不为零,且符号随 edge 翻转:

| edge (log_M 坐标) | POST 共同水平贡献 |
|---|---:|
| P_with_J | **+1.96467747** |
| J_with_P | +0.31409891 |
| P_without_J | −0.08182160 |
| J_without_P | **−0.58871450** |
| phase9 native_amplitude | −0.03437257 |

这是本文最关键的一张表。它说明 POST 对绝对标度的敏感性**不是一个固定的过增益**,
而是**内容条件化的、可变号的**响应。在 9 图相位面板上,内部内容分差的分解为
共同水平 −0.000667、相对差距 +0.000238、合计 −0.000429:**相对优势的正向作用
被共同水平的负向作用抵消**。

链路是:`M → query token 表示移动 → 与 reference tokens 相似度变化 → MaxSim → 决策`。
决定升降的不是 M 的标量大小,而是**表示移动是否朝向当前 reference 的内容方向**;
MaxSim 匹配位置切换再叠加一部分。

### 2.3 一个必须避免的循环论证

`sign(margin) == correct`:POST 486/486、NATIVE7 486/486、M_FREE 486/486,零例外。

这是**恒等式**,不是发现:`target_vs_strongest_wrong_margin` 定义为该头自身分数的
target 减最强 wrong。因此它既不能证明也不能反驳"POST 读绝对量"。要检验机制,必须
分解**内容分差**(如 §2.2),不能分解 margin。

> **原则 B(读出路径)**:同一 M 证据经不同计算方式,不具有相同的不变性。
> 成立条件:外部比值头 — 共同水平精确消去,可安全施加任意正标量缩放。
> 失效条件:内部表示调制 — 共同水平贡献非零且可变号,缩放不是无害操作。
> 证据:外部 0.0000000 全 scope;POST +1.96 至 −0.59 跨 edge 变号。

## 3. 第三问:能否据此预测和设计

### 3.1 已有的局部预测能力

在 120 query / 45 组 / 240 固定候选上,先测小幅扰动、封存预测、再验证更大扰动:
用各候选自己的响应斜率,内容分数预测误差比共享斜率低约 97–99%
(LOCAL_LINEAR MAE 2.29e-05 vs SHARED_LINEAR 1.61e-03,shift −0.04)。
共享斜率预测"同幅共同变化下配对差距不变",而候选各自的 reference 对齐斜率预测
非零差距,后者 MAE 1.09e-04 vs 实际 3.74e-03。

**边界(不可放宽)**:这是已探测候选上的新扰动,不是未见 query 的预测规律。

### 3.2 下游响应比不是常数 —— 这是设计约束,不是 bug

逐世界的 mean |Δmargin|(相对该头自己的 NATIVE,450 个世界决策):

| world | POST | NATIVE7 | M_FREE | POST/外部 |
|---|---:|---:|---:|---:|
| AMP_FLAT | 1.8136 | 0.1825 | 0.2150 | **9.1** |
| AMP_PERMUTE | 1.0836 | 0.1012 | 0.1297 | **9.4** |
| X_PLUS__001 | 0.2498 | 0.0258 | 0.0292 | 9.1 |
| X_MINUS__001 | 0.2388 | 0.0283 | 0.0379 | 7.2 |
| Y_PLUS__110 | 0.1153 | 0.0370 | 0.0399 | 3.0 |
| `__111` 族 | 0.019–0.036 | — | — | 2.2–3.1 |
| GLOBAL/LOCAL 相位 | 0.045–0.061 | — | — | 1.5–2.2 |
| ORIGINAL_HR1 | 0.2955 | 0.1713 | 0.1962 | 1.6 |
| ZERO | 3.9976 | 0.9467 | 1.0375 | 4.0 |

池化 4.31×;逐 component 4.43× CI[3.20, 5.71](16 components,逐值
0.7–9.8)。**跨世界变化 6 倍,且 `__001` 族(~7–9×)与 `__111` 族(~2–3×)
系统性分开。** 一个标量增益解释不了这个,压增益会同时压掉正向的那部分。

> **原则 C(改造方式)**:不要用标量重标定治内部反向。
> 成立条件:改造须作用在"表示移动方向 vs reference 内容方向"这一对齐关系上,
> 即候选条件化的响应,而非 M 的全局尺度。
> 失效条件:任何对 M 或 POST 输出的单一正标量缩放 —— 因为共同水平贡献
> 在不同 edge 上符号相反,单一缩放必然在一端恶化。
> 证据:§2.2 变号表 + §3.2 响应比 1.5×–9.4× 非常数。

### 3.3 回到实际收益:哪些 rescue 依赖什么

| 干预 | 外部 NATIVE7 | 外部 M_FREE | 内部 POST |
|---|---:|---:|---:|
| 原有纠错 | 10 | 10 | 8 |
| 相位/配准扰动 | 10 | 10 | 8 |
| 幅度打平 / 置换 | 10 | 10 | **6** |
| P 整条置零 | 7 | 6 | **2** |

**信息量集中在两格**:幅度族 8→6,以及置零(灾难性但无选择性)。其余世界全部保留,
而未变化的干预提供不了归因信息 —— 既不能说该性质必要,也不能说不必要(可能是扰动
未过阈值)。

两次实际翻转,逐例:

| | POST margin | NATIVE7 | M_FREE | 上游 target_logM | 上游 vs_strongest |
|---|---:|---:|---:|---:|---:|
| 106aa1a4 NATIVE→PERMUTE | +2.0469 → **−0.1846** | +1.2804→+1.3760 | +1.1454→+1.2445 | **+0.505** | **+0.212** |
| 2f5a93c3 NATIVE→PERMUTE | +2.3933 → **−0.1417** | +0.7703→+0.6403 | +0.8859→+0.7679 | **+0.452** | **+0.179** |

两例同形,且上游侧 target 是**受益**的(target_logM 与 vs_strongest 全为正)。
即:**上游证据变好,内部纠错反而消失,外部两头稳住。** 这否定"相对 M 优势更大
就必然更好"的简单解释,并把 §2.2 的抵消机制连到了真实 rescue 的存废上。

0476 的比例/绝对分离已单独记录:比值 14.877→19.757(变好),target 绝对 M
0.128082→0.077271(变差),POST action 2.046867→−0.184604(翻号)。

> **原则 D(证据可信度)**:上游相对优势不足以预测内部 rescue 存废。
> 成立条件:外部比值头 — 上游相对优势提升可直接预期不劣化(两例均保住)。
> 失效条件:内部调制头 — 上游相对优势提升时仍可能翻号(两例均翻)。
> 证据:上表两行,上游 +0.212/+0.179 对应 POST −2.23/−2.53。

## 4. 统一:共同保留的信息与各自成立条件

两条路径共同保留的,是 **候选间相对支持的序**(§1.1 的头部集中性);
它们的差别在**不变性**:

| | 外部比值头 | 内部表示调制 |
|---|---|---|
| 共同水平 | 精确消去 (0.0 全 scope) | 非零,**可变号** (+1.96…−0.59) |
| 利用的成分 | 相对差距 | 相对差距 **+** 绝对标度 **+** 交互 |
| 对上游扰动的响应幅度 | 1× 基准 | 1.5×–9.4×,依扰动类型 |
| 两次 AMP 事件 | 保住 (10/10) | 翻号 (8→6) |
| 可安全施加的操作 | 任意正标量缩放 | 无 |

**同一种候选判别证据(相对支持序)可经两种计算方式影响身份判断;外部路径以
损失绝对信息为代价换取不变性,内部路径保留绝对信息但因此获得变号风险。**
这不是"内部更差",而是两种路径的不变性结构不同 —— 内部的额外敏感性在四格分解
中既有 +1.96 也有 −0.59。

## 5. 未闭合(不写进设计原则)

1. **两次翻转的三因素逐例交叉分解未做**:绝对水平 / 候选响应差异 / MaxSim 匹配
   位置切换各承担多少,尚无逐例分摊。§2.2 的四格分解是组均值,不是这两例的分解。
2. **局部预测未证明可推广到未见 query**。现有边界是已探测候选上的新扰动。
3. **A/J/P 加性接口的唯一分摊不可识别**。解码器只见 A+J+P;任何"P 独有贡献"
   的分解都需要正交/无交互假设。交叉设计只能回答"是否可加",要回答"P 独有多少"
   需改接口,那是改模型不是改实验。
4. **上游承担多少原始收益仍未定量**。§1 给出的是选择性性质,不是收益分摊。
5. **相位 × 配准是并列实验,不是交叉因子设计**。
6. **不能断言"修好内部头就一定更好"**。§3.2 已证明标量修正不可行;方向性改造
   (原则 C)尚未实验验证。
7. 19 图选中事件队列不是未触碰的泛化证据;小面板独立核算不等于独立外部验证;
   区间未作多重比较校正。

## 6. 可交付的设计原则汇总

| # | 原则 | 成立条件 | 失效条件 |
|---|---|---|---|
| A | 秩选择性须配幅度门 | \|z\|≥0.5 且 sd 非最小 | 小 sd 零效应对照 → 假阳性 |
| B | 两路径不变性不同 | 外部:共同水平精确消去 | 内部:共同水平可变号 |
| C | 不用标量重标定治反向 | 改造须作用于对齐方向 | 任何单一正标量缩放 |
| D | 上游相对优势不预测内部存废 | 外部:可预期不劣化 | 内部:仍可翻号 |

**上游侧可陈述的结论**:RoMa 新增的判别信息表现为对候选场的整体重排,使正确身份
稳定进入前 10–20%(免疫共同水平,9 组一致);但它**不排除最强混淆者**
(vs_strongest 全部跨 0)。要排除最强混淆者,目标函数需直接作用于 `max_wrong`
而非 `mean_wrong` —— 现有机制在这一点上没有证据支持。这是新工作。
