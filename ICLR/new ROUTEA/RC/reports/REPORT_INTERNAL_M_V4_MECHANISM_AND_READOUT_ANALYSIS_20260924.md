# 内部 M V4：收益在哪里产生，在哪里丢失

2026-09-24。本轮继续分析封存的TRAIN16与跨组PROBE8；未启动训练、阈值搜索、RoMa或LLM推理。新增CPU计算仅用于检查现有适配器残差。PROBE8来自6个component且早期已打开，不是全新独立确认。

## 1. 内部质量条件已有作用，最终身份决策未得到probe净增

同一ColNomic自然C128；主模型末端为 `RAW差 + 条件化内容L + bias`，不能直接读取M。

| 评分口径 | TRAIN16 | PROBE8 |
|---|---:|---:|
| 原始自由内容L0直接取第一 | 8/16 | 4/8 |
| 内部真实M后的L直接取第一 | 12/16 | 5/8 |
| 同一适配器内部M换常量，L取第一 | 8/16 | 4/8 |
| 同一适配器内部M错绑，L取第一 | 8/16 | 4/8 |
| 原定联合训练终点头 | 10/16 | 4/8 |
| TRAIN16冻结适配器、重训读出头 | 11/16 | 4/8 |
| TRAIN16外部加性或乘积头 | 12/16 | 6/8 |

直接取L第一名是本轮**事后读出诊断**，不能改写预定主模型4/8，也不据此选用新模型。它定位到：至少部分有用排序已经形成，却被当前RAW/内容/接受权衡抵消。所有路径复用相同候选；probe另有1张目标根本不在C128。

## 2. 当前内部M主要产生共享特征偏移，而非已证实的区域选择

适配器读取每个patch的LayerNorm内容，以及广播到所有patch的同一个标准化logM；经16维GELU瓶颈后产生3584维残差，加在LLM输入前。没有输入query/reference局部可见性图或RoMa坐标。M仍可以与内容非线性交互，但没有直接给出“哪块区域更重要”。

CPU检查冻结128步适配器，在TRAIN16×128与PROBE8×128个候选条件下计算：

`delta_M(p) = residual(p, real M) - residual(p, standardized M=0)`。

将该向量场正交分成“跨patch均值向量”与“各patch偏离均值的部分”：

- 共享均值向量的能量占比中位数：TRAIN **99.43%**，PROBE **98.69%**。
- 全部3072对条件的共享占比都大于90%；这些候选不是独立统计样本。
- 以总能量加权后的patch变化部分占比：TRAIN **1.46%**、PROBE **2.15%**。
- M单独引起的残差相对原输入RMS中位数约TRAIN1.64%、PROBE1.44%。这与完整适配器残差不同。

因此，当前实现的更保守解释是：**将配对质量通过主要共享的特征方向变化带入后续内容评分。** 这并非统一乘一个常数；后续L2归一化和冻结LLM仍能把方向变化转成内容分数变化。上述占比只描述BF16舍入和LLM之前的输入残差，不能外推为LLM内部注意力、输出token或最终成绩的贡献占比，也不能据此说空间变化毫无作用。

从输出端看，`L(real M)-L(constant M)`与候选logM在每张probe内的相关系数为0.931–0.987，中位数0.957；TRAIN中位数0.969。它与共享调制证据一致，但相关性不证明该效果可以完全被一个标量公式替代。

## 3. 内容排序提升可以掩盖关键身份分差缩小

婴儿药目标 `766-e9-infants-pain-and-fever`：原始自由内容排名**23**，内部真实M后**2**；同一适配器常量M为39、错绑为70。23与39对应不同基线，不得混写。

但错误候选ChildsIbuprofen的M更高：0.09852对目标0.07365。原始内容中目标相对Childs的优势为0.0085486，内部调制后仅0.0004303，缩小**19.87倍**。真实M改善了总体排名，同时削弱了与这个强错候选的身份区分。

联合头为：

`z = -0.106569*dRAW + 25.425027*sym_L - 0.524142`。

目标与Childs之间，内容贡献仅+0.009203，RAW贡献却为-0.154240，总差-0.145037，导致Childs胜出。重训读出后这一对差距仍为负。因为`dRAW<=0`，负RAW系数在固定内容时更奖励RAW较低的挑战者。

这个负号已出现在V3 warmstart；训练集中存在深排名目标被救回，不能说是程序符号错误。删除RAW项也不会自动修复：本例内部L最高仍是错误Artrifin，目标第二。

外部头成功也不是M单独识别身份。它对目标相对Childs的优势分解为：

`+0.127365 RAW -0.106494 M +0.223050 原始内容 = +0.243921`。

这是当前“分开保留质量与原始内容”比“先混入单个内容分数”表现更好的一个具体例证，不是对所有内部条件化架构的否定。

## 4. 另一例确实受接受规则限制

`cefdinir-fig2`原始内容第二，内部真实M后第一；也是最佳挑战者。但联合头：

`+0.015543 RAW +0.123476 内容 -0.524142 bias = -0.385122`。

它没有超过HOLD=0。TRAIN内重训读出后仍为-0.076479。外部头的M项直接贡献+2.162931，最终接受正确候选。此处是有用排序没有获得足够接受分数，而非目标仍排在其它挑战者后面。

## 5. 已分清与尚未分清

已分清：M条件信号并未完全消失；至少部分内容排序获益；当前M响应主要是共享输入调制；某些关键身份分差被压缩；末端既存在竞争排序问题，也存在接受不足。独立FP64重建全部probe读出分数的最大误差2.67e-15，未发现分数公式或符号实现错误。

尚未分清：共享输入偏移经过LLM后究竟怎样改变token方向/匹配位置；更充分的TRAIN监督能否学到保留身份分差的调制；当前16张的训练组成、优化和读出形式各自对跨组失败贡献多少。不能把负RAW系数、偏置或共享调制中的某一项直接定为统一根因。

若继续模型开发，优先在TRAIN内检验两个明确问题：是否能保留原始内容对强错候选的区分，同时让质量参与表示；是否能使读出保留已形成的正确排序，再单独学习接受。无需继续盲目放大M，也不应依照已打开的8张手调偏置。新的方案必须另行冻结评估，不能用本分析为其预先宣告成功。
