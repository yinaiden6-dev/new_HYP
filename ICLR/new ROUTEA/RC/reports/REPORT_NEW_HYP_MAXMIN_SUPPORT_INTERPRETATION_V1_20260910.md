# new HYP：max-min支持值的解释规则

本说明只从已冻结pilot的数学定义和证书源码推导，不读取自然数据、
标签、结果或调度器；不提出新模型或新数值门。适用范围是固定C128、
原free-MaxSim向量a、任意非负且和为1的query-token支持。

## 1. 值究竟证明什么

令v_g=max_{p∈Δ} min_{h≠g} p·(a_g−a_h)。有限线性规划的对偶给出

    v_g=min_{alpha∈Δ} max_i [a_g(i)−sum_{h≠g} alpha_h a_h(i)]。

因此v_g≤0，当且仅当存在其它reference的一个凸混合，使其在每个
query token上都不低于a_g。不能只检查“是否有一个reference逐点压过g”；
即使没有单一压过者，多个reference的混合也可能构成对偶证书。

例如g=(1/4,1/4)，两个对手为(1,0)、(0,1)。它们各自都没有逐点压过g，
但各取1/2的混合为(1/2,1/2)，所以v_g=−1/4。这里的混合是不可分性的
数学证书，不是在正向评分中凭空创造一个真实错误物体。

反之，L>0给出一个实际可行非负支持，g在同一支持上严格胜过所有127
个其它reference。它证明这组冻结表示中的分离能力，不保证g是真实
目标、支持在空间上连通，或该支持唯一。

## 2. 为什么多个candidate都能为正

若a_1=(1,0)、a_2=(0,1)，其它126个profile均为(0,0)，candidate1取
p=(1,0)，candidate2取p=(0,1)，两者v都为1。每个candidate优化自己的
支持，所以不存在“只能一个v>0”的定理。多物体、不同文字部件或
偶然匹配均可能产生多个可分reference；正margin不等于用户意图。

## 3. 数值界和固定支持如何比较

本pilot保存精确端点意义下的L≤v_g≤U。L>0为正分离证书；U≤0为
该非负池化类的非正证书；跨0仍未决。U−L≤1e−8只关闭数值最优值
资格，不能把跨0的区间改写为已判正负。solver成功、超时或失败标记
均不能替代这些界。

原wq存在正质量时，令b为其精确归一化支持margin。因为它也是可行点：

    max(0,L−b) ≤ v_g−b ≤ U−b。

若保存的近似最优支持得到L<b，只说明这个具体数值见证稍弱，不能说
允许优化的函数类反而更差。若U=b，则固定支持已经达到此类最优值；
若L>b，则已严格证明存在更好支持。原clamped FP64 J须单列，不能未经
舍入分析直接代入b；零原wq没有对应simplex基线。

## 4. 哪些结果支持继续，哪些结果不能

- **工程先决条件**：全部512问题完成、精确界gap闭合并通过独立验证，
  才允许读取这4条TRAIN标签及评估后续cache。部分结果、数值未闭合
  或超时只阻止当前工程晋级，不记成科学不可分。
- **固定支持确实遗漏可分证据的情形**：TRAIN目标在原精确支持b≤0时
  获得L>0。这证明在这些样本中原支持错过了可分证据，可为构建完整
  label-free支持cache提供理由。仅有L>b而原b已经为正，只证明margin
  可提高；不说明会增加识别正确数。
- **排除的范围必须有限**：某个TRAIN目标U≤0，排除了这个query/reference
  在当前完整非负池化类中获得正margin；不能通过重新挑非负支持绕过。
  如果四个目标全如此，该pilot不给“恢复目标正分离”的全量cache正向
  依据，但仍不是其它query、其它表示或一般reference理论的不可能证明。
- **不得直接晋级的现象**：只有错误candidate出现正证书、多个candidate
  同时为正、或目标margin改善但未形成新增且保持的实际识别结果，都
  不满足用户的模型目标。4条已用TRAIN的能力描述不替代原EVAL32上的
  “保留原28并新增正确”，更不替代外部确认。

据此，pilot资格通过最多授权讨论下一阶段的理由，不自动启动全量
cache或新训练，不赋予HYP/ownership/部署GO。支持优化只可能改变当前
允许的权重分配；它不能从本身不存在的非负分离能力中制造证据。
