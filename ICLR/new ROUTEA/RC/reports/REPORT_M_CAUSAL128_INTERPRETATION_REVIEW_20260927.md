归因目标只有两个：什么信息使 M 区分正确候选与混淆候选；这种区分怎样经外部评分和内部表示改造产生作用。下列结论均来自已完成的本地代码与封存结果，不以更多正确数代替机制解释。

## 1. P 是什么，当前干预真正隔离了什么

`third_party/RoMaV2/src/romav2/matcher.py` 的 `_compute_match_embeddings` 对双图上下文特征作 softmax 匹配，再对 reference 的正弦／余弦位置特征取期望。对 query patch i：

\[
 P_i=\sum_j a_{ij}\phi(x_j),\qquad
 \phi(x)=[\sin(\Omega x),\cos(\Omega x)].
\]

它同时包含位置分布的多个频率矩，不能只称为集中度或一个空间坐标。其平方范数为

\[
 \|P_i\|^2=\sum_{j,k}a_{ij}a_{ik}
 \sum_f\cos\bigl(\omega_f^\top(x_j-x_k)\bigr).
\]

因此范数同时取决于概率权重与位置间关系，是所用频率下的分布聚合量；它不等于熵，也不是集中程度的唯一刻画。下面的性质解释来自该方程与实际干预代码，可直接复核。

| 干预 | 保留 | 改变 | 可以回答什么 |
|---|---|---|---|
| GLOBAL 相位平移 | 每个 patch 各频率的谱功率、范数，以及所有 P patch 之间的内积 | 所有 patch 一起作相同坐标平移对应的相位旋转；与固定 A/J 的对齐也可能改变 | 全局一致的变化下，预测器如何响应 |
| LOCAL 正负相位平移 | 每个 patch 各频率的谱功率与范数；正负配对平均后的扰动平方量与 GLOBAL 相同 | 不同 patch 使用不同平移符号，跨符号 patch 的相对关系被改变 | 超出逐 patch 谱功率的相对关系是否被预测器使用 |
| AMP_PERMUTE | patch 范数的全局分布、每个 P 向量的方向 | 把原有范数分配给不同 patch，改变幅度与位置／内容的绑定 | 有效性是否依赖幅度落在哪些 patch 上 |

GLOBAL 对所有 P_i 施加同一个正交分块旋转，故 P_i·P_k 不变；LOCAL 的旋转依赖 patch，通常不再保留这个关系。GLOBAL 与 LOCAL 的对比因而比“P 置零”更具体：它没有同时毁掉逐 patch 的谱功率。

但必须保留三个限制：

1. 实际预测器读入 A+J+P，而不是单独读取 P 的 Gram 矩阵。GLOBAL 仍可能改变 P 与 A/J 的相容性，所以该对照支持相对结构敏感性，不能唯一归因于真实物理几何。
2. 这不是改原图或恢复真对应；幅度重分配也不保证变换后的矩向量对应合法概率分布。所证是冻结计算系统内的性质作用。
3. “恢复相位”在主对照里指从 LOCAL 改为 GLOBAL，恢复一致的相对平移结构；**不是把 P 全部恢复为原生 NATIVE 值**。报告必须给出这一确切含义。

源代码：`programs/rc_roma_position_factor_v1.py`、`programs/rc_roma_property_restore_v2.py`。后者核查相位旋转谱功率的浮点舍入界，不按结果放宽科学干预。

## 4. 为什么高维空间过程可以经一个 M 被两种机制利用

这里能给出的是实现层解释与受限验证，不能把 M 宣称为身份充分统计量。

外部路径把 M 与原内容得分结合，再与原答案比较。对正数 a、b，忽略代码中防止除零的 epsilon，

\[
 (a-b)/(a+b)=\tanh\bigl((\log a-\log b)/2\bigr).
\]

因此在 M 与自由内容 L 都为正的范围，乘积对比把 log M 的候选相对优势与 log L 的优势相加，再作单调变换。这里需要保留的是对候选竞争有用的变化，不需要传回整张空间图。此方程只解释具体乘积特征；原 NATIVE7 还有其他列，不能把整个头等同于这一项。

内部路径把训练统计标准化后的 log M 与每个 patch 的已有内容一起输入残差模块，再经过冻结投影、归一化和自由 MaxSim。即使输入只有一个 M，内容不同的 patch 仍会产生不同变化；即使残差近似共有向量，加入不同原向量再归一化，也会改变与 reference token 的夹角。这和统一乘以一个正数再归一化不同。

历史 H593 五折固定 POST 分解提供了直接证据：保留共同残差分量时477/593、保留原54次纠错中的52次；仅空间差异分量430/593、保留6次。固定旧 MaxSim 指派仍保留44/54次纠错。这些支持“改变既有内容表示的比较方式”可以承担主要作用，不要求下游重新生成物体区域；也没有证明跨 query 只由 M 决定一个共享方向。共同方向仍可依赖 query 内容。

新9组反例还要求明确：POST实际分别计算 `L_t=f(q,r_t,log M_t)` 和 `L_w=f(q,r_w,log M_w)`。两候选的内容不同，输入又是各自绝对标准化的logM，因而两条有限响应不必有相同斜率。原幅度相位对照中，正确和错误的logM分别下降0.019992与0.037592，但POST内容分别下降0.000735与0.000306；正确内容下降更多，最终内容分差反向。这个结果与内容相关的非线性条件化一致，但本轮没有再单独拆开绝对尺度、内容依赖和非线性，不能指定其中一项为唯一原因。

所以当前可以连接的共同解释是：**候选相关的对应关系经冻结预测器压缩后，保留了能调整候选内容证据竞争的分量；外部通过分数联合，内部通过表示条件化读取这部分信息，其有效方向受幅度背景与读出方式制约。** 这不是外部与内部数学等价，不是恢复了同一空间掩码，也不证明所有高亮都准确。

证据：`programs/rc_prellm_m_adapter_v1.py`、`programs/rc_postllm_m_backend_v1.py`、`results/rc_postllm_h593_decomposition_v1/result.json`。

因此，**能明显改变M的性质，不一定就是能帮助身份区分的性质。** 这次相对结构与幅度绑定的对照给出了实际区分：前者在新组中有方向复验，后者主要改变整体数值，候选区分方向异质。第118号组的相位效果反向已保留，不能删去；原幅度下第101号也为微弱反向。

这里的“相对结构”仍是P计算编码的性质；不能跳成“物体真实几何已恢复”，也不能说范数信息无用。一个属性在这组固定干预里平均未增加身份分差，不排除其他场景或其他使用方式中的价值。

证据：`results/rc_m_causal128_attribution_chain_v1/phase_replication/result.json`、`phase_replication/validation.json`。

## 7. 固定阅读顺序与本轮完成边界

这部分是解释标准，不是追加数据选择或新的显著性门；主对比已经在协议中冻结。

1. 独立验收9组、18个固定候选、324个候选干预输出与原始两侧权重到 M 的重算。工程失败不归入科学负结果。
2. 首先报告预定主对比：幅度仍置换时的 GLOBAL−LOCAL 正确−固定错误 log M 分差；同时列9个组值、正负数量与组区间，不只列平均值。
3. 分开正确候选和错误候选各自的 log M 改变量。正分差可能来自正确更强、错误更弱，或两者一起变弱但错误变弱更多；不能统一叫“增强质量”。
4. 再报告三个预定次对比，不在结果后挑选轴、符号、query、错误对手或较好尺度；幅度与相位交互的正负必须保留。
5. 若主方向与旧7组一致且组区间排除0，可说在这组机制选择之外的历史数据上得到更强的方向复验；若区间含0，则方向性而不确定；若反向，明确限制旧解释，不能合并旧组稀释反证。
6. 主phase复验计算固定两候选上游M；新9组所有相位干预经原折冻结外部／内部模型传播的补充项也已单独通过验收，没有把旧7组传播冒充新9组传播。新组不能报告全 C128 准确率。

本轮最强可成立结论是：**在固定联合上下文和所测计算干预范围内，对应分布的跨patch相对结构贡献了超出逐patch谱功率的候选区分；其作用可经M影响外部校准和内部内容表示，并在新机制组上复现一个同向传播条件。原幅度与patch的绑定未显示同样稳定的身份价值，且存在保留配对判别的替代配置。**

重要反例同样属于结论：原幅度条件下，M分差改善却没有使内部内容分差改善；所以外部／内部的统一应表述为**同一支持信息接口与不同的条件读出**，而不是所有干预单调等价。当前凸补偿已充分优化，但未补回的性质影响仍只能限定当前数据和读出模型族。

这轮既定分析与必要的缓存补充已经完成。没有证明的更强命题是唯一因果、M的身份充分性、所有替代架构都无法补偿、完整C128的性质必要性，以及内部表示改造精确恢复了真实目标区域。这些不能因为本轮工程与有限四步闭环完成而自动获得证明。
