# 性质补偿与新组外部／POST 传播：第二次独立审查

本审查只读取已封存模型与输出，在 CPU 上复算标量算术和缓存后的适配器／投影层。未调用正式评测入口，未更新参数，未运行 RoMa、视觉编码器或 LLM，未修改原实验代码和结果。

审查产物位于 `results/rc_m_causal128_attribution_chain_v1/independent_property_review_v1/`：

- `validation.json`：TRAIN 数值证书、held 配对得分以及上游／下游 logM 闭合。
- `statistics_validation.json`：16 项组配对统计及探索性 bootstrap 的独立复算。
- `post_absolute_input_validation.json`：324 个候选干预的实际条件输入、patch 分数和匹配位置重播。

## 1. TRAIN 证书与信息边界

七个旧 TRAIN 组与九个新机制组的 component 没有交集。16 对元数据与原 128 候选轴、RAW 分数、自由内容分数、预先固定的最强自由内容错误候选逐项一致；最大差仅为 RAW 总体标准差的浮点归约误差 `6.75e-14`。

独立重建全部 112 条 TRAIN 特征、144 条 held 特征，均与封存值完全一致。四项共享 RMS 只来自七个 TRAIN 组的 GLOBAL 控制，共 28 个组内轴／符号重复；没有使用 held M 确定尺度或参数。模型没有截距、候选身份或 target-role 输入，交换一对候选严格将特征和得分取负。目标方向只用于监督排序损失。

五个模型的独立梯度无穷范数最大 `2.27e-12`，小于冻结门 `1.01e-10`；Hessian 最小特征值均不小于 `0.0010003768`，满足固定 ridge `0.001`；强凸 TRAIN 目标最优差上界最大 `4.49e-21`。因此，这些模型已在限定的四维／二维正则标量读出族内充分求解。该证书不证明表示充分、普遍不可替代或跨组泛化。

全部 held 得分独立复算误差不超过 `3.56e-15`，每组损失误差不超过 `2.23e-16`。16 个对比的逐组差、符号计数、均值及按九组重采样的区间全部复算一致，最大误差为零。RAW/L-only 在四个干预单元中逐值不变。

## 2. 新九组的四项性质对比与下游闭合

478 个来源绑定 SHA 一致。target、固定 wrong 及二者 logM 差共 12 项汇总对比，上游与新桥接最大差 `1.67e-16`；逐组对比最大差 `6.67e-16`。324 个 M／logM 入口与上游的最大差 `8.89e-16`。所有记录的 gap 均精确等于 target 端点减 wrong 端点，RAW 赢家的 HOLD 得分为零。

预先指定的主要对比为：幅度排列已打乱时，将局部不一致相位改为共同相位平移，即 `AMP_PERMUTE__GLOBAL − AMP_PERMUTE__LOCAL`。这里的 GLOBAL 是控制干预，不是原生 P。

| 同一对比的端点 | 九组均值变化 | 正向组 |
|---|---:|---:|
| target−wrong logM | +0.02417799 | 8/9 |
| 冻结 NATIVE7 action gap | +0.01708702 | 8/9 |
| 冻结 M_FREE action gap | +0.02532673 | 8/9 |
| 冻结 POST content gap | +0.00217926 | 8/9 |
| 冻结 POST action gap | +0.11582082 | 7/9 |

该条件下的性质变化确实沿同一 M 接口传入外部与内部读出，且没有重拟合模型。这是指定计算干预中的条件性传播证据。

## 3. 原幅度下的 POST 反向不是输入遗漏或候选串位

额外逐项重播九图、18 对、324 个干预的冻结 POST 适配器和投影层，全部 patch MaxSim 与 argmax **完全一致**，最大误差为零。直接在适配器 down 层注册只读 hook：最后一列精确等于该候选自己的 FP32 `log(M)`，经过原 TRAIN 的均值／标准差与固定 gain 变换；其它输入列是同一 query 的 patch hidden 经 LayerNorm 的结果，跨干预保持不变。

内部模块读取的是每个候选的**绝对 M 水平**，没有直接读取 target−wrong 的相对差。其后还有内容相关的残差、投影、归一化，以及面对不同 reference tokens 的自由 MaxSim。因此，相对 logM 优势变大，不蕴含内部内容优势必然同向。

在原幅度下，GLOBAL−LOCAL 的实际变化为：

| 端点 | target | fixed wrong | target−wrong |
|---|---:|---:|---:|
| logM | −0.01999159 | −0.03759164 | +0.01760005 |
| POST 内容分数 L | −0.00073490 | −0.00030560 | −0.00042930 |

两个候选的绝对 logM 都降低，wrong 降得更多；内部内容却是 target 降得更多。这两个事实能够同时成立，而且均由同一冻结模型的真实输入与输出复现。不能把该反向抹去，也不能仅凭它把唯一原因指定为某一层非线性；它说明相对判别信息到内部内容读出的传递具有条件依赖。

## 4. 补偿实验怎样解释

| 性质单元 | 冻结 GLOBAL 头的 held 损失 | 在该单元的旧七组重训后 | RAW/L-only |
|---|---:|---:|---:|
| 原幅度 GLOBAL | 0.37986809 | 0.37986809 | 0.76861990 |
| 原幅度 LOCAL | 0.39471961 | 0.40055343 | 0.76861990 |
| 打乱幅度 GLOBAL | 0.33683592 | 0.30012822 | 0.76861990 |
| 打乱幅度 LOCAL | 0.35145578 | 0.31880299 | 0.76861990 |

原幅度 LOCAL 的单独重训没有恢复 GLOBAL 的 held 损失：剩余差 `+0.02068534`，8/9 组更差，探索性组 bootstrap 区间 `[+0.00287591,+0.04509152]`。与此同时，打乱幅度的两单元在该配对读出上的均值反而更好；不能由这组结果宣称原幅度及全部上游成分各自必不可少。也不能把非显著的补偿或剩余差解释成等价。

上述补偿是**固定 target／wrong 的标量读出诊断**，不是原 COST1 的全 C128 决策，不含 HOLD，也没有重训 RoMa 预测器。四个轴／符号只是组内重复。九个组相对既往 F71 机制分析是新组，但早已属于打开过的 H593，不是未触碰的外部确认集。

本审查支持有限干预下的性质效应、同接口传播与限定模型族补偿的算术及实现正确性；不支持唯一因果、普遍必要性、完整空间中介或身份充分性声明。
