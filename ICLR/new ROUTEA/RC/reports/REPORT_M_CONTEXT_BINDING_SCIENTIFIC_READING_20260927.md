# A/J/P配准实验：绝对支持、比例区分与内部利用的分界

本报告解读完整九组：9个query，每个query固定target/wrong两个候选，共18个query-reference pairs，各29臂，并完成同组冻结NATIVE7、M_FREE、POST传播。这是9组target/wrong比较，不是18组。它没有新增模型或前向，不是全C128检索评测。九组均已打开；下列区间是探索性组bootstrap。完整七种对比、所有四方向及逐组数据均在独立核算附件，不能只据某一方向或正向对比下结论。

## 最重要的新认识

**保持P自身张量完全不变，改变它与A/J上下文的配准，仍会改变M；但“支持值更高”“比例区分更强”“内部内容差更大”“最终纠错”是四个不同端点。它们在这次实验里没有一起同向变化。**

主对比为四方向内平均的 `(000+111−001−110)/2`：两种配准状态分别在两种绝对摆放下比较。A开关同时移动两层appearance特征，J/P分别控制其循环移位。

| 主配准对比的端点 | 九组平均变化 | 探索性95%区间 | 正向组数 |
|---|---:|---:|---:|
| target logM | +0.056083 | [+0.039478, +0.073280] | 9/9 |
| wrong logM | +0.057445 | [+0.038435, +0.078460] | 9/9 |
| target−wrong logM差 | −0.001363 | [−0.020763, +0.017139] | 6/9 |
| target−wrong 原始M差 | +0.002857 | [+0.000871, +0.005062] | 7/9 |
| 外部NATIVE7 action差 | −0.002825 | [−0.023383, +0.015466] | 6/9 |
| 外部M_FREE action差 | −0.003845 | [−0.027895, +0.017706] | 6/9 |
| POST内容差 | +0.002533 | [+0.000399, +0.005406] | 6/9 |
| POST action差 | +0.131071 | [−0.001990, +0.323616] | 5/9 |

这里不能只看logM差，然后说“没有任何身份倾向”。原始M差和POST内容差有正向信号；也不能只看POST内容差，然后说“最终纠错已经稳定改善”。主对比的action差区间仍包含0。

## 配准影响了什么

保持P完全不动、仅共同移动A/J的 `110−000`，使target/wrong的logM分别平均下降0.048596和0.048348，两侧均为8/9组下降。它否定了“M只由这一份P张量独立决定”的解释：同一P在不同上下文摆放下会产生不同支持值。但A/J相对解码网格的位置同时改变，不能单用这个对比宣称纯语义绑定。

主配准对比平衡两种摆放后，target与wrong均9/9得到更高绝对支持。这说明当前冻结接口存在跨分量配准效应；它并未在比例尺度上证明正确候选得到更多支持。target logM的增量约0.0561，wrong约0.0574，两者差异不稳定。

**原始M差与logM差不同是实质区别，不是计算矛盾。** 若两候选近似获得共同乘法因子k，则 `log(kMt)−log(kMw)` 不变，而 `kMt−kMw=k(Mt−Mw)` 会缩放。不同原始M基值、逐候选响应和非线性均可能参与本次差异；当前对照没有证明它恰好是一个共同k。实测主对比的target原始M增加0.004619，wrong增加0.001762。

因此更准确的判断是：**本次配准更稳定地改变了两侧的支持水平；没有证实比例区分增强，但放大原始尺度差的信号存在。** 这将“上游有用”与“下游怎样读取标度”连接起来，而不是把一切重新命名为质量。

## 为什么外部与POST不同

同一批干预值进入同一冻结模型后，POST的target内容增加0.004482，wrong内容增加0.001949，两侧也均9/9增加，内容差平均增加0.002533。POST没有直接复制logM差：它接收候选的绝对logM和已有内容表示，由同一适配器形成新的tokens，再进行自由内容匹配。因此相近的logM增量可以在不同内容与初始M位置产生不同的内容变化。

这是实际干预传播已经看到的结果，不能由此唯一断言是某个patch、某条内部方向或某个非线性部件在承担作用。它也不等于适配器已经单独学会身份分类。外部头使用M及其代数派生量与原内容证据，而POST通过M改变内容读出；同一上游变化经过两种固定读出，不必产生相同的候选差。

条件J×P对比同样应完整保留：A固定时POST内容差增加0.005080、action差增加0.264525；A移动时分别增加0.004990、0.260904。两种条件下这些探索性区间均为正，但这是预先指定的次级交互比较，不能替换主对比，也不能当成新的独立确认。三阶交互的区间包含0。

本传播实验只替换M及其代数派生量；外部原局部权重形状与内容固定，POST沿用原tokens及原折模型。只有固定target/wrong改变，若RAW赢家是第三候选就保留其原M/L。因此这里的action差不是完整128候选排名，更不是全H593的新增正确数。

## 已排除与仍未排除的解释

1. **P被意外破坏或数值漂移：已排除本协议检查范围内的实现问题。** 576次完整逆移位恢复通过。移位保持各场的向量集合、channel Gram、Fourier幅度与环绕结构；主P固定对照连P的完整网格排列都不变。A两层同步移动，原生回放和池化独立验收通过。
2. **共同移动应当完全无影响：不成立。** 111保持逐patch元组，总和及真实LayerNorm均与移位严格交换；但DPT的卷积、padding、resize与池化不具有完全平移等变性。111逆移位后的confidence差RMS平均约0.367，范围约0.212–0.844。这个数是**原始confidence logit**的RMS，不能读作0–1权重误差。
3. **主logM差不稳定只是exact token池化造成：当前没有支持。** 用整幅sigmoid置信度均值构成M，主gap仍为−0.000863，区间同样跨0。但两者都是全局均值，不能排除完整confidence空间场中仍有被压缩丢失的身份信息。
4. **配准必然带来更强身份比例：本轮没有建立。** 不显著不等于等价或没有作用；主gap的区间约为[−0.0208,+0.0171]，九组精度有限。
5. **P场内结构因此是唯一根因：不能推出。** 配准、P内部坐标组织、场强度、解码网格和内容读出仍可交互；有限干预不会排除所有替代机制。

相加接口本身还有一个明确限制：DPT只接收A0与实际 `A1+J+P`。若J/P的补偿变化保持A0和实际总和完全相同，下游无法区分它们。这是“唯一归到J或P”在该接口处的结构不可辨识性，不是再多跑几个相同删除对照就能消除的。

## 与旧GLOBAL/LOCAL相位结果的关系

旧GLOBAL/LOCAL干预固定query网格承载点，旋转P所编码的reference对应坐标：统一旋转与逐位置局部旋转的区别，测试的是跨位置对应关系的组织一致性。本次循环移位则把完整P向量搬到另一个query网格位置，并保留P场的环绕组织结构；它测试输入场之间的配准与解码网格响应。

两者不是重复实验。旧相位一致性的正向信号不会被这次比例gap近零直接推翻；这次结果也不证明旧相位效果完全由P场内结构单独造成。可以成立的当前归因是：**保持哪些信息，比笼统地称“空间”或“质量”更重要；场间配准可影响绝对支持，而相对比例、绝对差和内容条件化的响应需要分别验证。**
